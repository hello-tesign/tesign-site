왜 볼 만한가

윈도우나 맥은 TV로 화면 보내기가 기본인데, 리눅스에서는 잘 되는 방법을 찾기 어렵다. 만든 사람도 노트북 영화를 TV로 보려다 아무것도 안 돼서 직접 만들었다고 밝힌다.

이걸로 무엇을 만들 수 있나

  • Miracast(WFD), DLNA, 크롬캐스트 세 가지 방식으로 화면을 보낸다. 트레이 앱은 시스템 언어를 따라가고, KDE·GNOME 웨이랜드에서는 화면 공유 창(xdg-desktop-portal)을 거쳐 화면을 잡는다.

누구에게 맞나

리눅스 노트북으로 영상을 보거나 발표 화면을 TV에 띄우려는 사람.

5분 안에 시작하기

# fluxcast.dev의 문서에서 설치 안내를 따른 뒤, 트레이에서 TV를 골라 연결한다.

주의할 점

  • README 기준 출시 수준으로 확인된 것은 WFD(Miracast) 방식뿐이다. DLNA는 대체용, 크롬캐스트는 실험 단계이며 시험한 삼성 TV에서는 동작하지 않았다. Hyprland 같은 wlroots 계열 환경에 맞춰져 있다.
