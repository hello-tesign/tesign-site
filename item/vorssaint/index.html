왜 볼 만한가

맥 사용자가 하나씩 따로 사는 유틸리티(앱별 볼륨, 시스템 모니터, 앱 전환기, 창 스냅, 클립보드 기록, 언인스톨러)를 메뉴 막대 아이콘 하나 뒤에 모았습니다. 계정·텔레메트리·구독이 없고, 설정의 Features 화면에서 기능을 통째로 설치·제거할 수 있어 제거한 기능은 로드조차 되지 않아 CPU·메모리를 쓰지 않습니다. 2026년 6월 첫 커밋 뒤 README 기준 3일 만에 GitHub 트렌딩 상단에 올랐고, 현재 별 18,627개입니다.

이걸로 무엇을 만들 수 있나

  • GPL 소스(Swift)라 앱별 오디오 라우팅이나 창 스냅 같은 개별 기능의 구현을 참고해 자기 도구를 만들 수 있습니다. 단 이름·아이콘·외형은 TRADEMARKS.md로 따로 보호되므로 포크는 새 정체성이 필요합니다.
