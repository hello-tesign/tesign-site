왜 볼 만한가

AI 비서에게 일을 맡기려면 파일을 두고 웹을 열고 결과를 쌓아 둘 자리가 필요하다. Memoh는 비서마다 파일 저장소·바탕화면·브라우저·네트워크·장기 기억을 갖춘 작업 공간을 하나씩 준다. 내 컴퓨터를 꺼도 그 자리는 살아 있다.

이걸로 무엇을 만들 수 있나

  • Go로 만들어졌고 AGPL-3.0 라이선스다. 내장 에이전트를 내 API 키로 돌릴 수도 있고, 이미 쓰던 Claude Code나 Codex를 이 작업 공간 안에 올려 쓸 수도 있다. 텔레그램·디스코드·웹 화면 등으로 말을 건다.

누구에게 맞나

자료 조사나 반복 작업을 AI에게 오래 맡기는 사람, 여러 비서를 동시에 굴리는 팀.

5분 안에 시작하기

# memoh.ai에서 화면을 먼저 보고, 직접 설치할지 가입해서 쓸지 정한 뒤 모델 API 키를 준비한다.

주의할 점

  • 모델 사용료는 직접 부담한다(자기 API 키를 넣는 구조). AGPL-3.0이라 고쳐서 서비스로 제공하면 소스를 함께 공개해야 한다.
