왜 볼 만한가

코드는 읽히려고 쓰이지만 정작 감상의 대상이 되는 일은 드뭅니다. Programming Museum은 hello, world부터 디자인 패턴·고전 알고리즘·오픈소스에서 빌려 온 파일까지를 전시실별로 걸고, 작품마다 큐레이터 노트를 달아 왜 볼 만한지 적습니다. 강연실은 무료이고 어린이 놀이터에서는 코드를 직접 움직여 봅니다. 로그인·유료 벽·광고가 없고 방문자 정보를 모으지 않는다고 밝히며, 빌려 온 작품은 MIT나 Unlicense인 것만 원 커밋에 고정해 겁니다.

이걸로 무엇을 만들 수 있나

  • 신입 온보딩에 쓰는 '고전 코드 읽기' 투어 코스
  • 코딩 수업에서 한 작품씩 놓고 이야기하는 감상 수업
  • 사내 코드베이스의 명작을 같은 형식으로 거는 내부 전시
