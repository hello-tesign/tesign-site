## TESIGN TAKE

AI 없이 같은 결과가 나오는 점검이라, 고친 뒤 다시 돌려 확인하기 좋다.

## 왜 볼 만한가

테스트를 따로 짜는 일이 번거로워 사이트를 고치고도 제대로 도는지 확인하지 못하는 경우가 많다. assay는 페이지의 버튼과 입력 요소를 스스로 찾아 전부 써 보고, 잘못된 동작을 알려 준다.

## 이걸로 무엇을 만들 수 있나

- 크로미움으로 페이지를 열어 화면의 조작 요소로 검사 항목을 만든다. 예를 들어 태그 필터를 두 번 눌렀는데 목록이 원래대로 돌아오지 않으면 그 사실과 전·후 화면을 함께 보여 준다. 테스트 코드도, LLM도, API 키도 필요 없고 실행할 때마다 결과가 같다. 코딩 에이전트용 스킬도 있다.

## 누구에게 맞나

- 직접 만든 웹페이지를 배포 전에 점검하고 싶은 개발자.

## 5분 안에 시작하기

```
# pip install assay-ui로 설치한 뒤 점검할 페이지 주소로 실행한다.
```

- 파이썬과 크로미움이 필요하다. 별 98개로 공개된 지 얼마 안 됐다.
