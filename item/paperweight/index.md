## TESIGN TAKE

소스가 공개돼 있어 어디에 무엇을 보내는지 직접 확인할 수 있다.

## 왜 볼 만한가

잊어버린 가입 계정과 광고 메일이 쌓여 개인정보가 어디 퍼졌는지 알기 어렵다. Paperweight는 메일함을 읽어 서비스별 계정과 메일링 리스트를 찾아내고, 유출 사고 여부와 삭제 요청 초안을 보여 준다.

## 이걸로 무엇을 만들 수 있나

- 지메일, 마이크로소프트, 애플, 프로톤(브리지) 메일과 IMAP을 지원한다. 계정 목록과 메일링 리스트 찾기, 유출 알림(haveibeenpwned.com), 대량 수신거부 기능이 있고, 메일과 설정은 내 컴퓨터에 남으며 외부 서버로 보내지 않는다고 밝힌다. 보통 2분 안에 훑는다고 한다.

## 누구에게 맞나

- 쌓인 가입 계정과 광고 메일을 정리하고 싶은 일반 사용자.

## 5분 안에 시작하기

```
# 저장소의 Releases에서 내 운영체제용 파일을 받아 메일을 연결하고 훑어본다.
```

## 주의할 점

- 무료는 메일 계정 하나와 찾기·살펴보기까지다. 수신거부·삭제 같은 정리 실행, 여러 계정, MCP는 유료(30일 이용권 또는 연간 Pro)다. 내가 쓰는 메일 전체를 읽는 앱이므로 권한 허용 전에 소스와 요금제를 직접 확인해야 한다.
