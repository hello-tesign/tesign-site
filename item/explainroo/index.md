## TESIGN TAKE

저장소 주소와 주제만 에이전트에게 알려 주면 시작할 수 있다.

## 왜 볼 만한가

짧은 설명 영상 하나를 만들려고 목소리 녹음과 편집, 영상 도구를 따로 다루기는 부담스럽다. explainroo는 에이전트에게 주제를 말하면 대본과 그림을 쓰게 하고, 나머지를 알아서 처리해 MP4 파일을 준다.

## 이걸로 무엇을 만들 수 있나

- 에이전트가 대본(script.md)과 장면(scenes.js) 두 파일을 쓰면, 오픈 음성 모델 Kokoro가 읽어 주고 Whisper가 단어별 타이밍을 맞춰 그림이 말에 맞춰 나타난다. 계정도 API 키도 필요 없다. 종이·칠판·청사진 등 화면 스타일 예시가 있다.

## 누구에게 맞나

- 제품·개념 설명 영상을 직접 만들고 싶은 사람, 코딩 에이전트 사용자.

## 5분 안에 시작하기

```
# README의 안내 문장을 에이전트에게 붙여 넣고 주제를 적는다. 에이전트가 저장소를 받아 AGENTS.md를 따라 진행한다.
```

## 주의할 점

- 코딩 에이전트가 필요하고, 지금은 Claude Code와 Opus 5.5에서 가장 잘 동작한다고 적혀 있다. 별 약 300개로 공개된 지 얼마 안 됐다.
