왜 볼 만한가

게임마다 DLSS 파일을 손으로 바꾸면 원본을 잃기 쉽고, 어떤 게임에서 되는지는 해 봐야 압니다. DLSS 5 Swapper는 Steam·Epic·GOG·Game Pass 폴더를 스캔해 게임별로 설치·복원·백업을 관리하고, DLSS가 없는 게임은 Feeder 경로로, 오래된 API는 dgVoodoo 경유로 다룹니다. F8 오버레이로 게임 중에 슬라이더를 만지고, 같은 그래픽카드 사용자의 보고를 커뮤니티 페이지에서 봅니다. Windows 10/11 전용 MIT 무료 앱이며, 안티치트 게임은 크래시나 계정 정지 위험을 경고합니다.

이걸로 무엇을 만들 수 있나

  • 라이브러리 전체에 같은 설정을 넣고 되돌리는 개인 관리 루틴
  • 게임·카드별 결과를 모아 두는 커뮤니티 리포트
  • 오래된 DX9·에뮬레이터 게임에 뉴럴 렌더링을 얹는 실험

누구에게 맞나

PC 게이머
RTX 카드로 여러 게임에 DLSS 5를 넣어 보고 싶을 때
에뮬레이터 이용자
옛 콘솔 게임 화질을 올려 보고 싶을 때

5분 안에 시작하기

# 최신 릴리스 페이지에서 Windows 설치 파일 또는 포터블 버전 내려받기
# 같은 페이지의 SHA256SUMS.txt로 체크섬 확인
# Feeder 경로는 Visual C++ 런타임(x64, 32비트 게임은 x86도) 필요

주의할 점

  • 안티치트 게임은 크래시·계정 정지 위험 — 앱이 경고만 하고 우회하지 않음
  • OptiScaler 경로의 기본 모델은 RTX 50 계열에서만 돌아갑니다
  • Linux 바이너리는 없고 Proton은 실험적 커뮤니티 소스뿐입니다
