왜 볼 만한가

HTML 페이지를 만드는 건 쉬워졌지만, 데이터를 저장하려면 결국 어딘가에 호스팅해야 하는 문제가 남아 있었습니다. Capsule(러스트·Tauri 2.0으로 제작, 제작자의 Show HN 글 기준)은 HTML 앱과 관련 파일을 SQLite 데이터베이스 하나에 그대로 담아 .capsule 파일로 만듭니다. 데이터는 localStorage 방식의 키·값이나 몽고DB풍 컬렉션으로 같은 파일 안에 저장되고, PDF·이미지 같은 첨부파일도 함께 담깁니다. 문서는 기본적으로 파일시스템에 접근할 수 없고 인터넷 접근에도 권한이 필요하며, 여러 사람이 각자 만든 사본을 나중에 병합할 수 있도록 각 데이터에 고유 UUID와 타임스탬프를 붙입니다.

이걸로 무엇을 만들 수 있나

  • 레시피·체크리스트 같은 개인용 데이터 앱을 만들어 파일 하나로 가족에게 보내기
  • 인터넷 연결 없이(비행기·지하철에서도) 쓸 수 있는 도구를, 웹 미리보기 없이 데스크톱에서 열어보기
  • 문서별 AI 기능(로컬·원격 모델)을 직접 붙여 보기

누구에게 맞나

가족·소모임에 작은 데이터 앱을 나눠주고 싶은 사람
호스팅 없이 파일만 보내고 싶을 때
오프라인 환경에서 쓸 도구가 필요한 사람
