왜 볼 만한가

위성이나 항공기 움직임을 보려면 보통 전문 도구를 깔고 데이터 소스를 따로 붙여야 합니다. gods-eye-view는 그 과정을 브라우저 한 화면으로 옮겨, 공개된 실시간 데이터를 사실적인 3D 지구본 위에 바로 얹습니다. Pinokio로 설치하거나 터미널에서 직접 실행해 내 브라우저에서 열며, Cesium을 기반으로 만들어졌습니다. 다만 저장소에 라이선스가 표기돼 있지 않아 그대로 가져다 쓰기 전에 확인이 필요합니다.

이걸로 무엇을 만들 수 있나

  • 공개 위성 데이터를 띄워 두는 사내 브리핑용 지도 화면
  • 지리·우주 수업에 쓰는 실시간 관측 데모 페이지

누구에게 맞나

교사·강사
항공·위성·지진을 실시간으로 보여 주는 수업
데이터 개발자

OSINT 입문자

5분 안에 시작하기

# Node.js 24.14+ 필요 · 실행 후 http://localhost:4173 을 엽니다
$ git clone https://github.com/bilawalsidhu/gods-eye-view.git
$ cd gods-eye-view
$ npm ci
$ npm run doctor
$ npm run dev

주의할 점

  • 사실적 3D 지구본과 음성 조작은 Cesium ion·Google·OpenAI 키가 필요합니다
  • 데이터가 지연·추정될 수 있어 항법·긴급 대응 등에는 쓰지 말라고 명시
  • GitHub 메타데이터엔 라이선스가 없지만 README는 MIT라고 밝힙니다
