왜 볼 만한가

탐색기를 대체하거나 파일 구조를 바꾸지 않고, 실제 폴더에 연결된 위젯을 바탕화면 위에 얹어 파일을 정리합니다. README는 이를 Stardock Fences 같은 도구의 오픈소스 대안으로 위치시키고, 할 일·빠른 메모·검색·날씨·음악 위젯은 부가 기능으로 둡니다. 현재 1.5.1이며 x64·ARM64 설치 파일이 .NET 10 Native AOT와 Windows App Runtime 2.4를 내장해 오프라인 설치가 됩니다.

이걸로 무엇을 만들 수 있나

  • C#·WinUI 3·.NET 10 Native AOT에 Rust 네이티브 셸 계층을 붙인 구조라, 바탕화면 층 위젯이나 Native AOT 배포를 만드는 WinUI 3 개발자에게 참고가 됩니다. 단 외부 PR은 현재 받지 않으므로 기여보다는 읽기·포크 용도입니다.

5분 안에 시작하기

# 1. GitHub Releases에서 DeskBox_Setup_1.5.1_x64.exe(인텔·AMD) 또는 DeskBox_Setup_1.5.1_arm64.exe(Snapdragon 등 Windows on ARM) 내려받기
# 2. 함께 올라온 .sha256 파일로 해시 확인(설치 파일은 현재 미서명)
# 3. 설치 실행 — 기본은 현재 사용자 계정에 설치, 트레이에서 조용히 시작
# 4. 검색 위젯의 파일 검색을 쓰려면 Everything을 별도 설치

주의할 점

  • 라이선스 GPL-3.0-only(이전에 MIT로 나온 버전은 MIT 유지). 무료, 계정·클라우드 없음.
  • Windows 10 21H2(빌드 19044) 이상, 전체 시각 효과는 Windows 11 22H2 이상. 설치 파일이 미서명이라 실행 전 해시 확인 권장. 날씨·업데이트 확인은 네트워크 사용.
  • 1인 개발, 외부 PR 미수용. 파일 검색은 Everything 별도 설치 필요.
