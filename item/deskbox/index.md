## TESIGN TAKE

파일은 탐색기의 보통 파일·폴더 그대로이고, 위젯은 그 위에 얹힐 뿐이라는 것이 이 도구의 핵심 약속입니다.

## 왜 볼 만한가

탐색기를 대체하거나 파일 구조를 바꾸지 않고, 실제 폴더에 연결된 위젯을 바탕화면 위에 얹어 파일을 정리합니다. README는 이를 Stardock Fences 같은 도구의 오픈소스 대안으로 위치시키고, 할 일·빠른 메모·검색·날씨·음악 위젯은 부가 기능으로 둡니다. 현재 1.5.1이며 x64·ARM64 설치 파일이 .NET 10 Native AOT와 Windows App Runtime 2.4를 내장해 오프라인 설치가 됩니다.

## 이걸로 무엇을 만들 수 있나

- C#·WinUI 3·.NET 10 Native AOT에 Rust 네이티브 셸 계층을 붙인 구조라, 바탕화면 층 위젯이나 Native AOT 배포를 만드는 WinUI 3 개발자에게 참고가 됩니다. 단 외부 PR은 현재 받지 않으므로 기여보다는 읽기·포크 용도입니다.

## 누구에게 맞나

- 바탕화면이 어지러운 윈도우 사용자 — 폴더 기반 위젯 정리, 캡슐 모드로 접기
- Fences 유료 사용자 — 무료 GPL 대안 시험
- WinUI 3 개발자 — .NET 10 Native AOT와 Rust 셸 계층 구조 참고

