왜 볼 만한가

WSL 컨테이너를 쓰려면 명령어를 직접 쳐야 한다. RC Desktop은 도커 데스크톱 같은 화면에서 컨테이너를 보고 켜고 끄게 하면서, 전자(Electron) 앱 없이 가볍게 시작되도록 만들었다고 밝힌다.

이걸로 무엇을 만들 수 있나

  • 컨테이너 시작·중지·재시작·삭제, 로그와 inspect 보기, 이미지·볼륨·네트워크 목록을 지원한다. 새 컨테이너는 입력 양식, docker-compose 파일, docker run 명령 붙여 넣기 세 방식으로 만들고, 컴포즈 묶음을 한 번에 켜고 끈다.
