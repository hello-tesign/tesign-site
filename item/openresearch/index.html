왜 볼 만한가

자료 조사를 에이전트에 맡기면 한 번에 하나씩 돌아가서, 갈래가 여럿인 주제는 시간이 그만큼 길어집니다. openresearch는 조사 에이전트를 병렬로 띄우고 모델은 쓰는 쪽에서 고르게 합니다. Rust로 쓰였고 MIT 라이선스이며 별도 홈페이지가 있습니다. 저장소 설명이 한 줄뿐이라 지원 모델과 사용법은 문서에서 확인해야 합니다.

이걸로 무엇을 만들 수 있나

  • 경쟁사와 시장을 갈래별로 나눠 돌리는 사내 조사 도구
  • 모델을 바꿔 가며 결과를 견주는 비교 실험

누구에게 맞나

연구자
가설 여러 개를 병렬로 실험하고 기록을 남길 때
ML 엔지니어
실험 변형을 git 기반 트리로 추적할 때
기획자
경쟁사·시장 조사를 갈래별로 나눠 돌릴 때

5분 안에 시작하기

# macOS·Linux CLI(Windows는 릴리스 페이지에서 설치, 베타):
$ curl -LsSf https://openresearch.sh/install.sh | sh
$ orx up
# 로컬 대시보드가 http://127.0.0.1:4791 에 뜹니다

주의할 점

  • Claude Code·Codex·OpenCode·Cursor 중 하나가 설치돼 있어야 합니다
  • 공식 빌드는 사용 통계를 보내며 orx telemetry off로 끕니다
  • Windows 지원은 베타이며 Git for Windows가 필요합니다
