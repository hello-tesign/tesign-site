왜 볼 만한가

코드베이스, 위키, Obsidian 볼트 등 마크다운이 든 기존 폴더를 그대로 열어 Google Docs나 Notion처럼 위지윅으로 편집합니다. Claude, Codex, OpenCode, Pi 같은 에이전트와 나란히 편집하는 기능이 들어 있고, 컴퓨터에서 감지된 에이전트에 MCP와 스킬을 설치하는 안내를 앱이 해 줍니다. 데스크톱 앱(macOS·Windows·Linux) 또는 `npm install -g @inkeep/open-knowledge` 뒤 `ok start --open`으로 웹 UI를 띄울 수 있습니다.

이걸로 무엇을 만들 수 있나

  • LLM 위키나 '두 번째 뇌'를 위한 스타터 팩으로 구조화된 지식 베이스를 만들고, MCP로 자기 에이전트가 문서를 검색·작성하게 할 수 있습니다. 팀 공유·자동 동기화는 git/GitHub 기반입니다.

누구에게 맞나

스펙과 문서를 에이전트와 나란히 작성
소규모 팀
git/GitHub 기반 공유와 자동 동기화

5분 안에 시작하기

# npm install -g @inkeep/open-knowledge   # Node.js 24+ 와 git 필요
# cd your-project
# ok init          # 프로젝트 스캐폴드 + AI 편집기 연결(Claude Code, Claude Desktop, Cursor, Codex, OpenCode, OpenClaw)
# ok start --open  # 웹 편집기를 띄우고 브라우저에서 열기
# # 데스크톱 앱: openknowledge.ai/download 에서 DMG / Setup / deb·rpm

주의할 점

  • 라이선스 GPL-3.0-or-later. README는 'Private, local, and free'라고 명시. 홈페이지 구조화 데이터 기준 무료(가격 0 USD), 유료 플랜 표기 없음(2026-09-15 확인).
  • 데스크톱 앱은 macOS Apple Silicon·Windows 10+(x64/Arm64)·Linux(x64/arm64). 인텔 맥과 서버는 CLI 웹 앱으로. 웹 앱은 Node.js 24+와 git 필요.
  • AI 편집은 사용자가 이미 쓰는 Claude·Codex 등 하네스에 의존(각 서비스 비용은 별도). 최신 릴리스 v0.72.1(2026-09-15 확인). 개발사 Inkeep.
