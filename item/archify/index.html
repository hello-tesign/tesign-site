왜 볼 만한가

구조도는 한 번 그려 두면 금방 낡고, 고칠 때마다 그리기 도구를 다시 여는 일이 반복됩니다. archify는 코딩 에이전트가 쓰는 스킬 형태라, 코드 옆에서 구조·워크플로·시퀀스·데이터 흐름·라이프사이클 다이어그램을 만들어 냅니다. 결과는 의존성 없는 HTML 한 파일이라 그대로 열거나 내보낼 수 있습니다. MIT 라이선스입니다.

이걸로 무엇을 만들 수 있나

  • 저장소 구조를 설명하는 온보딩 문서용 도식
  • 고객 제안서에 넣을 시스템 흐름도 한 장
  • 배포할 때마다 다시 그려 붙이는 아키텍처 페이지

누구에게 맞나

백엔드 개발자
온보딩 문서용 구조도를 계속 갱신해야 할 때
기술 컨설턴트
제안서에 넣을 시스템 흐름도가 필요할 때
테크 리드
PR 전후 아키텍처 변경을 비교해 보여 줄 때

5분 안에 시작하기

$ npx skills add tt-a1i/archify -g
# 설치 없이 써 보려면(Codex 예):
$ npx skills use tt-a1i/archify@archify --agent codex
# 에이전트 채팅에서 시스템 설명을 주고 Archify로 그려 달라고 요청

주의할 점

  • Cursor·Claude Code·Codex·OpenCode 등 에이전트 호스트와 Node.js가 필요합니다
  • 기본 설정에서 안내용 업데이트 확인 요청을 보냅니다(환경변수로 끌 수 있음)
  • Mermaid 자동 변환·WYSIWYG 편집은 범위 밖이라고 밝힙니다
