왜 볼 만한가

ChatGPT로 코드를 다루려면 파일을 복사해 붙이고 결과를 다시 옮기는 일이 반복됩니다. Chat On Steroids는 데스크톱 앱과 Chrome 확장을 짝지어, ChatGPT 대화가 승인한 폴더의 파일을 읽고 고치고 터미널을 열어 두게 합니다. 작업을 워커 여러 개로 나누고, Compact & Resume으로 세션을 새 대화에 이어 갑니다. ChatGPT 대화를 쓰므로 Codex 할당량은 소모하지 않고 MIT로 공개돼 있지만, 아직 서명되지 않은 베타 빌드입니다.

이걸로 무엇을 만들 수 있나

  • 로컬 저장소를 ChatGPT 구독만으로 고치는 개인 작업 환경
  • 독립된 일감을 워커에 나눠 맡기는 병렬 작업 흐름
  • 긴 작업을 새 대화로 이어 가는 세션 이관 절차

누구에게 맞나

5분 안에 시작하기

# Releases에서 Windows·macOS(Apple Silicon)·Linux 설치 파일을 내려받아 설치
# Settings → Workspace에서 작업할 프로젝트 폴더를 승인
# Settings → Setup으로 Core를 연결하고 ChatGPT 개발자 모드에 추가
# Chrome 확장 폴더를 열어 Load unpacked로 불러오면 자동으로 짝지어짐
# 모델을 고르고 작업을 적어 보내기

주의할 점

  • Windows는 서명 없음, macOS는 서명·공증 없음 — 체크섬 확인 권장
  • ChatGPT 개발자 모드와 커스텀 MCP 앱이 되는 계정이 필요합니다
  • OpenAI와 무관한 프로젝트라고 README가 밝힙니다
