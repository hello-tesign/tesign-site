왜 볼 만한가

인터뷰나 강의, 방송 다시보기처럼 긴 영상에서 볼만한 순간만 골라내는 일은 품이 많이 든다. AutoClip은 자막과 음성을 AI로 분석해 하이라이트 구간과 제목을 뽑고, 자막을 입힌 짧은 클립과 모음집을 자동으로 만든다.

이걸로 무엇을 만들 수 있나

  • 데스크톱 앱(맥·윈도)과 도커 웹 화면, CLI/MCP 세 가지 방식으로 쓸 수 있다. 로컬 영상이나 유튜브·빌리빌리 링크를 넣으면 자막을 준비하고 AI가 점수를 매겨 구간을 나눈 뒤, 통이치엔원·오픈AI 호환·제미나이·오라마 로컬 모델 중 골라 분석을 맡긴다. 틱톡·유튜브 쇼츠 등 발행 연동은 v1.3.2부터 지원한다.

누구에게 맞나

인터뷰·강의·방송 다시보기에서 짧은 영상을 뽑아야 하는 콘텐츠 제작자, 편집 시간을 줄이고 싶은 팟캐스터.

5분 안에 시작하기

# GitHub Releases에서 맥·윈도 설치 파일을 받아 열고, 설정에서 쓸 AI 모델의 API 키를 넣은 뒤 영상을 가져온다.

주의할 점

  • AI 분석에는 통이치엔원·오픈AI 등 모델 제공사의 API 키가 필요하다(로컬 오라마 모델은 무료). 인터페이스는 중국어가 기본이지만 v1.3.1부터 한국어를 포함한 8개 언어를 지원한다.
