왜 볼 만한가

에이전트 설정은 스킬 몇 개, 규칙 몇 줄씩 흩어진 채로 쌓이기 쉽습니다. ecc는 스킬·습관·기억·보안·조사 우선 개발을 하나의 하네스 구성으로 묶어, Claude Code·Codex·Opencode·Cursor 같은 도구에 같은 방식으로 얹습니다. JavaScript로 쓰였고 MIT 라이선스이며 별도 문서 사이트가 있습니다.

이걸로 무엇을 만들 수 있나

  • 팀이 함께 쓰는 에이전트 기본 설정 한 벌
  • 도구를 바꿔도 그대로 옮겨 가는 개인 작업 규칙

누구에게 맞나

팀 리드
에이전트 기본 설정을 팀 전체에 같게 맞출 때
개발자
Claude Code·Codex를 오가며 같은 규칙을 쓰고 싶을 때

5분 안에 시작하기

# Node.js 18+ · Git · Claude Code 2.1+ 필요
$ npx ecc-universal@2.2.1 setup
# 또는 Claude Code 프롬프트에서:
# /plugin marketplace add https://github.com/affaan-m/ECC
# /plugin install ecc@ecc
# 한 하네스에 설치 방법을 두 가지 겹치지 마세요

주의할 점

  • 같은 하네스에 설치를 두 번 겹치면 스킬·훅이 중복 실행됩니다
  • Windows 네이티브는 일부 기능에 미해결 결함이 있다고 밝힙니다
  • 훅이 세션마다 컨텍스트를 주입해 토큰 사용이 늘 수 있습니다(기본 8000자)
