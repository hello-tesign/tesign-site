왜 볼 만한가

에이전트 구성은 프롬프트와 도구를 바꿔 가며 손으로 맞춰 보는 일이 대부분입니다. SoL-Pi는 이 과정을 자동 연구 루프로 돌리는 방법을 다루며 NVlabs 계정으로 공개돼 있습니다. TypeScript로 쓰였고 MIT 라이선스이며 프로젝트 페이지가 따로 있습니다. 연구 성격이 강해 바로 설치하는 제품이라기보다 방법을 읽고 가져오는 쪽에 가깝습니다.

이걸로 무엇을 만들 수 있나

  • 하네스 설정을 자동으로 비교하는 사내 실험 루프
  • 연구 방식을 지금 구성에 옮겨 보는 검토 노트

누구에게 맞나

Pi 사용자
반복 턴과 긴 로그 재읽기로 토큰이 새는 것을 줄일 때
에이전트 연구자
하네스 효율 실험의 결과물을 살펴볼 때

5분 안에 시작하기

# Node.js 22.19+ · npm 필요
$ npm install --global @earendil-works/pi-coding-agent@0.84.2
$ pi install git:github.com/NVlabs/SoL-Pi
# 모든 기능은 기본 꺼짐 — ~/.pi/agent/sol-pi.json 에서 켭니다

주의할 점

  • Pi 0.84.2 전용 확장이며 Pi의 공식 배포판이 아닙니다
  • 기능은 전부 옵트인이라 설정 파일이 없으면 아무것도 켜지지 않습니다
  • Reducer 기능은 로그를 외부 모델로 보낼 수 있어 SECURITY.md 확인이 필요합니다
