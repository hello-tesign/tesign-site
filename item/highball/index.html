요약이며 법적 조언이 아닙니다.

왜 볼 만한가

맥에서 윈도우 게임을 돌리는 도구는 Wine 빌드를 직접 고르고, 되는지는 깔아 봐야 압니다. Highball은 Wine·DXMT·D3DMetal·DXVK를 알아서 설정하고 Steam이나 Epic 라이브러리를 붙인 뒤, 게임별 렌더러 판정과 안티치트 차단 목록을 CC0 공개 데이터베이스에서 가져와 내려받기 전에 보여 줍니다. 앱과 CLI는 GPL-3.0, 데이터는 CC0이며 유료 등급은 없다고 못 박습니다. macOS 14 이상 Apple Silicon 전용이고 아직 베타입니다.

이걸로 무엇을 만들 수 있나

  • 게임 사기 전에 맥 호환 여부를 조회하는 개인 체크리스트
  • 사무실 맥에서 쓸 윈도우 전용 프로그램 실행 환경
  • CC0 호환 데이터를 가져다 쓰는 자체 조회 페이지

# Apple Silicon · macOS 14+ · 첫 실행은 엔진 내려받기로 시간이 걸림

주의할 점

  • Apple Silicon과 macOS 14 이상에서만 돌아갑니다
  • 베타 단계이며 첫 실행에 15~25분이 걸릴 수 있습니다
  • D3DMetal은 Apple 라이선스를 따로 수락해야 합니다
