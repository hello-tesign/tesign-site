왜 볼 만한가

데스크톱 펫은 대개 전용 런타임 위에 얹혀 무겁거나 특정 OS에만 있습니다. BongoCat은 C·SDL3·OpenGL로 다시 짠 네이티브 앱으로, 키보드·마우스·게임패드 입력을 로컬에서 읽어 Live2D 모델을 움직이고 Windows·macOS·Linux를 모두 지원합니다. 입력을 기록하거나 올리지 않고 광고·분석 코드가 없다고 밝히며, Microsoft Store와 GitHub Releases에서 받을 수 있습니다. 소스는 AGPL-3.0, 기본 모델 에셋은 MIT입니다.

이걸로 무엇을 만들 수 있나

  • 방송 화면 구석에 두는 반응형 마스코트
  • 자체 캐릭터 모델을 얹은 브랜드 데스크톱 펫
  • SDL3·OpenGL 입력 처리 구조를 읽는 C 학습 자료

5분 안에 시작하기

# Microsoft Store 또는 GitHub Releases에서 최신 버전 내려받기
# 소스 빌드는 CMake 3.24+ · C11/C++17 컴파일러 · OpenGL 개발 파일 필요
# Live2D 렌더링에는 Cubism SDK for Native를 따로 넣어야 함

주의할 점

  • 소스는 AGPL-3.0 — 배포 형태에 따라 조건 확인 필요
  • Cubism SDK 없이 빌드하면 진단용 백엔드만 만들어집니다
  • 첫 빌드 구성은 의존성 내려받기로 네트워크가 필요합니다
