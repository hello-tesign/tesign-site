## TESIGN TAKE

기능이 하나뿐이라 오히려 판단이 쉽다. 메뉴 막대가 빽빽한 사람에게는 바로 효과가 보이고, 아닌 사람에게는 필요 없다.

## 왜 볼 만한가

메뉴 막대는 항상 자리가 모자란다. 아이폰이 와이파이·배터리·데이터를 한 덩어리로 묶어 보여 주는 방식에서 착안해, 맥에서는 데이터 대신 소리를 넣어 세 가지를 아이콘 하나에 담았다.

## 이걸로 무엇을 만들 수 있나

- 스위프트로 만든 맥 전용 네이티브 앱이고 Apache-2.0 라이선스다. 아이콘 크기를 16~36pt에서 고를 수 있고 기본값은 28pt다. 유선 연결일 때 표준 와이파이 아이콘을 쓰도록 선택할 수도 있다.

## 누구에게 맞나

- 작업 표시줄이 늘 꽉 차 있는 맥 사용자, 화면이 좁은 노트북을 쓰는 사람.

## 5분 안에 시작하기

```
# statustrio.lingai.net에서 내려받아 설치하고, 아이콘 크기를 화면에 맞게 한 번 조정해 둔다.
```

## 주의할 점

- macOS 전용이다. 애플과 무관한 개인 프로젝트라고 만든 쪽이 직접 밝히고 있다.
