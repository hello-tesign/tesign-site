## TESIGN TAKE

공개 데모가 "동작은 흉내만 낸다"고 분명히 적어 둔 채 화면을 전부 열어 둔다. 설치 전에 쓸지 말지 판단할 수 있게 해 주는, 흔치 않은 배려다.

## 왜 볼 만한가

cPanel이나 Plesk는 쓸 만하지만 매달 사용료가 붙는다. LaraNode는 같은 일을 하는 관리 화면을 내 서버에 직접 올려 쓰는 방식이고 사용료가 없다. 서버 한두 대를 터미널로만 관리하기 번거로운 자리를 메운다.

## 이걸로 무엇을 만들 수 있나

- 라라벨(PHP)로 만들었고 우분투 24.04 이상, 1vCPU·2GB 메모리·10GB 디스크가 최소 조건이다. 사이트 만들기, Let’s Encrypt SSL 한 번 누르기, 직접 만든 파일 관리자, MySQL 데이터베이스, 사이트마다 PHP 7.4~8.5 지정, UFW 방화벽, CPU·메모리·네트워크 실시간 확인이 들어 있다. 백업은 계정 전체나 파일·데이터베이스 단위로 서버 안, S3, SFTP에 보관 주기를 정해 둘 수 있다. 관리자와 일반 사용자 권한도 나눈다.

## 누구에게 맞나

- VPS 한두 대에 사이트를 올려 두고 관리하는 1인 사업자나 소규모 팀, 호스팅 사용료를 줄이려는 사람.

## 5분 안에 시작하기

```
# demo.laranode.com에서 실제 화면을 둘러보고, 새로 만든 우분투 서버에 설치 명령으로 올린다.
```

## 주의할 점

- 이미 쓰고 있는 서버에 얹는 용도가 아니라 새로 만든 서버에 설치해야 한다. 우분투와 Apache·MySQL·PHP 조합을 전제로 한다. 데모 모드는 실제 사이트를 관리하는 서버에서 절대 켜면 안 된다고 안내하고 있다.
