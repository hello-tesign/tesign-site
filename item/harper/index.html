왜 볼 만한가

만든 사람이 README에 이유를 직접 적어 뒀다. 기존 검사기는 비싸고 참견이 많으며, 무엇보다 쓴 글이 전부 회사 서버로 전송된다는 점이 문제였다. 다른 대안은 메모리를 기가바이트 단위로 먹었다. Harper는 기기 안에서 도니 네트워크를 오가는 대기 시간도 없다.

이걸로 무엇을 만들 수 있나

  • Rust로 작성됐고 Apache-2.0 라이선스다. 검사가 기기 안에서 끝나기 때문에 인터넷 연결 없이도 동작한다.

누구에게 맞나

영어로 업무 메일·제안서·문서를 쓰는 사람, 그리고 원고가 외부 서버로 넘어가면 곤란한 직군.

5분 안에 시작하기

# writewithharper.com에서 문장을 붙여 넣고 검사 결과를 먼저 확인한다. 쓰던 편집기에 붙이는 방법은 같은 사이트의 안내를 따른다.

주의할 점

  • 영어 전용이다. 한국어 맞춤법은 검사하지 않는다.
