## 왜 볼 만한가

팀 코드를 우리가 통제하는 곳에 두고 싶어도 GitHub Enterprise나 GitLab을 운영하는 일은 부담이다. GitOrange는 익숙한 GitHub 화면을 그대로 두고, 서버·디스크·깃 데몬 관리 없이 쓰게 한다고 밝힌다.

## 이걸로 무엇을 만들 수 있나

- 저장소는 클라우드플레어 Artifacts에, 나머지는 D1에 저장한다. 기존 .github/workflows 파일을 같은 문법으로 클라우드플레어 컨테이너에서 돌려, 빌드·테스트 같은 흔한 흐름은 고치지 않고 동작한다고 한다.

## 누구에게 맞나

- 클라우드플레어를 쓰는 소규모 개발팀, 코드를 자체 관리하고 싶은 팀.

## 5분 안에 시작하기

```
# README의 Quickstart를 따른다. 클라우드플레어 Workers 유료 요금제, 이메일 발송용 도메인, Node.js 20 이상이 필요하다.
```

## 주의할 점

- 클라우드플레어 유료 요금제(월 몇 달러)가 필요하고, 쓰는 Artifacts는 아직 공개 베타다. 저장소 비밀값(시크릿)은 아직 지원하지 않는다.
