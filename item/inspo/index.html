왜 볼 만한가

AI에게 화면을 맡기면 기능은 만들지만 보기 좋게는 못 만든다. Inspo는 실제로 운영 중인 사이트 832곳, 2,320쪽을 데스크톱과 모바일로 담고 색·글꼴·구조를 정리해 둔 뒤, 에이전트가 작업 중에 꺼내 볼 수 있게 MCP로 연결한다.

이걸로 무엇을 만들 수 있나

  • MCP 서버다. 사이트마다 색의 역할·글자 크기 단계·여백 규칙·CSS 변수를 정리한 설명 문서가 있고, 히어로·가격표·푸터·내비게이션 같은 기준 부품 68개는 붙여 쓸 수 있는 JSX로 제공한다. 도구 15개로 검색하고 불러온다.

누구에게 맞나

클로드 코드나 커서로 화면을 만드는 사람, 디자이너 없이 제품 화면을 짜야 하는 팀.

5분 안에 시작하기

# inspomcp.dev의 안내를 보고 쓰는 도구에 MCP 서버로 등록한 뒤 화면을 하나 만들어 본다.

주의할 점

  • 모아 둔 자료는 다른 회사가 운영 중인 사이트를 담은 것이다. 참고로 볼 것이지 그대로 베끼는 용도가 아니다. 공개된 지 얼마 되지 않아 앞으로 바뀔 수 있다.
