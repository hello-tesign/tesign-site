왜 볼 만한가

두 기기 사이에 네트워크가 없거나 믿을 수 없을 때, Decimen은 파일을 애니메이션 QR 코드의 끝없는 스트림으로 화면에 띄우고 다른 기기의 카메라가 그것을 읽어 파일을 복원합니다. 화면→카메라 링크에는 되돌아오는 채널이 없으므로 분수 부호(Luby transform)를 써서 수신 측이 임의의 순서로 약 K×1.15개 프레임만 모으면 복원되며, 놓친 프레임은 시간만 늦출 뿐 결과를 망치지 않습니다. 49인치 모니터→iPhone 17 Pro Max 구간에서 1.0MB를 2.5초, 지속 418.5KB/s로 전송한 기록이 실행 리포트와 함께 공개되어 있습니다.

이걸로 무엇을 만들 수 있나

  • 스트림을 APNG나 PNG 시퀀스로 내보내 영상 강의나 배포 페이지에 넣으면, 재생 화면에 카메라를 대는 누구나 같은 파일을 받을 수 있습니다. 소스는 npm으로 자체 호스팅되고 독립 실행 페이지 두 개로도 빌드되므로 격리망 안 배포에 응용할 수 있습니다.

누구에게 맞나

격리망·회의실 등 네트워크가 막힌 환경
화면과 카메라만으로 설정 파일이나 문서 전달
낯선 기기에 짧은 텍스트·파일을 넘길 때
계정·페어링·클라우드 없이 양쪽 브라우저만 열어 전송
부호 이론·브라우저 카메라 처리에 관심 있는 개발자
공개된 프로토콜 문서와 벤치마크 실행 리포트

5분 안에 시작하기

# 1. 두 기기 모두 https://decimen.app/ 을 열기 — 설치 없음, 한쪽은 Send, 다른 쪽은 Receive
# 2. 직접 돌리려면:
# npm install
# npm run dev
# 보내는 기기에서 https://localhost:5173/send/ , 받는 폰에서 터미널에 표시된 Network URL 열기(자가 서명 인증서 1회 허용)

주의할 점

  • 라이선스 AGPL-3.0-or-later(v0.4.0부터; v0.3.0까지의 릴리스는 MIT로 남음). 자체 호스팅·수정 배포 시 AGPL 의무 적용.
  • 암호화 없음 — 보내는 화면이 보이는 카메라는 누구나 읽을 수 있음. 파일 64MB, 텍스트 4MB 한도.
  • 웹 앱(PWA)이라 카메라 권한만 필요; 속도는 화면 크기·카메라에 크게 좌우(폰→폰 기록은 199.2KB/s). 홈페이지 기준 v0.5.3.
