왜 볼 만한가

제품 데모 영상은 녹화보다 그 뒤 편집에서 시간이 더 듭니다. recordly는 편집 기술을 요구하지 않는 쪽으로 만들어져, 녹화를 끝내면 그대로 보여줄 만한 영상이 나옵니다. 데스크톱 앱이라 macOS·Windows·Linux에 설치해 쓰고, 저장소 설명은 무료임을 밝히고 있습니다. GitHub 메타데이터에는 라이선스 항목이 없지만 README는 AGPL 3.0을 명시합니다.

이걸로 무엇을 만들 수 있나

  • 기능이 바뀔 때마다 찍어 두는 사내 사용법 영상
  • 랜딩 페이지에 올릴 제품 데모 클립
  • 고객 문의 답장에 붙이는 화면 녹화 안내

$ yay -S recordly-bin
# 실행 → 화면·창 선택 → 녹화 종료 시 편집기가 열립니다

주의할 점

  • GitHub 메타데이터엔 라이선스가 없지만 README는 AGPL 3.0이라고 밝힙니다
  • Linux는 커서 숨김이 안 되고 시스템 오디오에 PipeWire가 필요합니다
  • macOS 시스템 오디오 녹음은 macOS 14 이상에서만 됩니다
