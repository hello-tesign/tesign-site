## TESIGN TAKE

지표를 게임 카드로 바꾸는 장난이지만, 연간 상을 로그 스케일로 판정해 커밋 스팸이 통하지 않게 한 설계는 진지하다.

## 왜 볼 만한가

여섯 스탯은 GitHub GraphQL API에서 읽은 실제 수치다 — PAC는 지난 1년 커밋, SHO는 스타, PAS는 PR+팔로워, DRI는 언어 다양성, DEF는 리뷰+이슈, PHY는 생애 기여. 원시 스탯은 88에서 캡이 걸리고 90대는 연차와 영향력으로만 열리는 '레거시 게이트'라 한 해 몰아쳐도 아이콘이 되지 않는다. 카드 URL은 스탯이 바뀌면 스스로 다시 채점되며, 홈페이지 카운터는 약 125만 장(2026-09-15 조회)을 표시한다.

## 이걸로 무엇을 만들 수 있나

- README나 포트폴리오에 `gitfut.com/<username>.png`를 넣는 것이 기본 용도. 연간 상(발롱도르) 판정 공식(yearScore = 4·log(commits) + 3·log(PRs) + …)이 공개돼 있어 팀 내부 랭킹 카드 같은 변형의 참고가 된다.
