요약이며 법적 조언이 아닙니다.

왜 볼 만한가

작은 제조 회사도 견적·수주·작업지시·품질 기록을 엑셀과 여러 프로그램에 흩어 두기 쉽다. Carbon은 복잡한 조립, 위탁 생산, 대량 생산, 주문형 사양 제작을 겨냥한 제조용 운영 시스템을 소스 전체를 공개한 채 제공한다.

이걸로 무엇을 만들 수 있나

  • 웹 앱으로, 고객·견적 요청·견적·수주·청구서 같은 영업 화면과 생산(MES), 품질(QMS) 기능을 갖췄다. 관리형 클라우드로 쓰거나 직접 서버에 설치할 수 있다.

누구에게 맞나

주문 생산·조립·위탁 생산을 하는 중소 제조 회사, 사내 시스템을 직접 운영하려는 담당자.

5분 안에 시작하기

# carbon.ms/self-hosted의 자체 설치 안내를 따르거나, carbon.ms에서 관리형 클라우드로 시작한다.

주의할 점

  • 핵심은 AGPL-3.0이지만 엔터프라이즈 파일(packages/ee 폴더와 파일 이름에 .ee.가 들어간 파일)은 별도 상용 라이선스다. 'Carbon' 이름과 로고 사용권은 어느 라이선스에도 포함되지 않는다. 관리형 클라우드는 사용자당 월 요금제다.
