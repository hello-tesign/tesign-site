## TESIGN TAKE

사이드로딩에서 가장 막히는 첫 단계를 한 화면에 모아 둔 점이 실용적이다.

## 왜 볼 만한가

SideStore 같은 도구로 앱스토어 밖 앱을 쓰려면 처음 설치와 페어링 파일 준비가 까다롭다. iloader는 이 과정을 버튼 몇 개로 줄였다.

## 이걸로 무엇을 만들 수 있나

- 윈도·맥·리눅스용 데스크톱 앱이다. 아이폰을 USB로 연결하고 애플 ID로 로그인하면 SideStore(정식·나이틀리), LiveContainer+SideStore 설치나 IPA 가져오기를 고를 수 있고, 페어링 파일·인증서·앱 ID도 관리한다.

## 누구에게 맞나

- 앱스토어에 없는 앱을 아이폰에 설치해 쓰려는 사람.

## 5분 안에 시작하기

```
# usbmuxd를 준비하고(윈도는 아이튠즈, 맥은 기본 포함) GitHub Releases나 iloader.app에서 받은 앱을 열어 아이폰을 연결한 뒤 애플 ID로 로그인한다.
```

## 주의할 점

- 애플 ID 로그인이 필요하다. README에 따르면 공식 배포처는 저장소와 iloader.app뿐이고 홈브루 캐스크는 비공식이다.
