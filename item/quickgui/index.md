## TESIGN TAKE

저장소 스스로 '진지한 용도로 쓰지 말라'고 적은 실험작이라, 지금은 방향을 구경하는 쪽이 맞습니다.

## 왜 볼 만한가

데스크톱 앱을 웹뷰로 감싸면 만들기는 쉬워도 화면이 무거워지는 문제가 따라옵니다. quickgui는 웹뷰를 쓰지 않고 GPU에서 바로 그리는 방식을 시험하는 GUI 프레임워크입니다. Rust로 쓰였고 홈페이지가 따로 있습니다. 저장소가 스스로 실험 단계임을 밝히고 있어(README 기준 라이선스는 MIT OR Apache-2.0), 지금은 살펴보는 쪽에 가깝습니다.

## 이걸로 무엇을 만들 수 있나

- 웹뷰 없이 띄워 보는 데스크톱 화면 시제품
- 렌더링 방식을 견줘 보는 성능 비교 실험

## 누구에게 맞나

- 데스크톱 앱 개발자 — 웹뷰 없는 GUI 프레임워크를 눈여겨볼 때
- Go·Rust 개발자 — 쓰던 언어로 네이티브 창을 띄워 보고 싶을 때

## 5분 안에 시작하기

```
# Bun 1.4+ 필요(Go 1.23+ 또는 Rust 툴체인, macOS는 Xcode CLT)
$ bunx @quickgui/cli init my-app
```
