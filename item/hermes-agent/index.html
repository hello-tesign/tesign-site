왜 볼 만한가

에이전트를 바꿔 탈 때마다 설정과 맥락을 처음부터 다시 쌓아야 하는 점이 번거롭습니다. hermes-agent는 '쓰는 사람과 함께 자라는 에이전트'를 내걸고 Nous Research 계정으로 공개돼 있습니다. Python으로 쓰였고 MIT 라이선스이며 별도 문서 사이트가 있습니다. 저장소 설명이 한 줄뿐이라 실제 동작은 문서에서 확인해야 합니다.

이걸로 무엇을 만들 수 있나

  • 매일 쓰는 개인 작업용 상시 에이전트
  • MIT 라이선스로 가져와 고쳐 쓰는 에이전트 뼈대

5분 안에 시작하기

# Linux · macOS · WSL2 · Termux:
$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
# Windows(PowerShell):
$ iex (irm https://hermes-agent.nousresearch.com/install.ps1)
$ source ~/.bashrc
$ hermes

주의할 점

  • 설치가 curl | bash 방식이라 스크립트를 먼저 읽어 보는 편이 안전합니다
  • 모델 제공자(API 키 또는 Nous Portal 구독)를 직접 연결해야 합니다
  • Windows에선 uv.exe가 백신에 오탐될 수 있다고 README가 안내합니다
