왜 볼 만한가

새 사람이 들어올 때마다 개발 환경 맞추는 데 며칠이 간다. Coder는 그 환경을 Terraform으로 정의해 두고 필요할 때 띄운다. 안 쓰는 환경은 자동으로 꺼져 비용이 줄고, 접속은 보안 터널을 통한다.

이걸로 무엇을 만들 수 있나

  • Go로 만들어졌고 AGPL-3.0 라이선스다. 작업 공간을 Terraform으로 정의하며 EC2 가상 머신, 쿠버네티스 파드, 도커 컨테이너 등을 쓸 수 있다. AI 코딩 에이전트를 회사 인프라 안에서 돌리되 API 키는 작업 공간에 두지 않는 구조도 함께 제공한다.

누구에게 맞나

개발자가 여럿인 팀, 외부 인력이 드나드는 프로젝트, 코드를 개인 노트북에 두면 안 되는 조직.

5분 안에 시작하기

# coder.com의 빠른 시작 문서를 따라 시험용 서버에 한 번 올려 보고, 쓰던 환경을 Terraform으로 옮기는 분량을 먼저 가늠한다.

주의할 점

  • 직접 서버를 운영해야 한다. AGPL-3.0이라 고쳐서 서비스로 제공하면 소스 공개 의무가 따르고, 일부 기능은 유료 Premium으로 분리돼 있다.
