왜 볼 만한가

코딩 에이전트에 일을 맡기면 시키지 않은 추상화와 옵션까지 딸려 오는 일이 잦습니다. ponytail은 에이전트를 '가장 게으른 시니어 개발자'처럼 굴게 만들어, 쓰지 않아도 되는 코드를 먼저 덜어 내는 쪽으로 판단을 돌립니다. Claude Code·Cursor 같은 도구에 스킬과 규칙 형태로 붙여 쓰고, MIT 라이선스로 공개돼 있습니다.

이걸로 무엇을 만들 수 있나

  • 팀 코딩 규칙에 맞춘 사내 에이전트 기본값
  • 리뷰 전에 군더더기를 걷어 내는 사전 점검 규칙

누구에게 맞나

1인 개발자
에이전트가 시키지 않은 추상화까지 만들 때
팀 리드
리뷰 전에 군더더기를 걷어 내는 기본 규칙이 필요할 때

5분 안에 시작하기

# Claude Code 프롬프트에 두 번에 나눠 입력:
# /plugin marketplace add DietrichGebert/ponytail
# /plugin install ponytail@ponytail
# Codex:
$ codex plugin marketplace add DietrichGebert/ponytail
$ codex plugin add ponytail@ponytail

주의할 점

  • Claude Code·Codex 플러그인은 Node.js가 PATH에 있어야 훅이 돕니다
  • GPT-5.5처럼 추론 토큰을 많이 쓰는 모델에선 비용이 되레 늘 수 있다고 밝힙니다
  • 절감 수치는 저장소 자체 벤치마크 값입니다
