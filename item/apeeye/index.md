## TESIGN TAKE

탭을 닫으면 503으로 분명히 끊긴다고 미리 적어 둔다. 어중간하게 살아 있는 것보다 이렇게 딱 끊기는 편이 오히려 헷갈리지 않는다.

## 왜 볼 만한가

화면을 먼저 만들 때 서버가 아직 없으면 진도가 막힌다. Apeeye는 브라우저에서 컬렉션 이름 하나만 적으면 그 자리에서 진짜 주소가 생겨, 내 앱에서도 curl이나 포스트맨에서도, 동료 컴퓨터에서도 호출된다.

## 이걸로 무엇을 만들 수 있나

- 자료는 브라우저의 IndexedDB에만 저장되고 서버에는 아무것도 남지 않는다. 중계 서버가 들어온 요청을 열려 있는 내 탭으로 넘기고 탭이 답하는 구조다. GET·POST·PUT·PATCH·DELETE를 상태 코드와 함께 지원하고, 작업 공간 전체를 JSON으로 내보내고 들여올 수 있다. 직접 내려받아 로컬에서 돌릴 수도 있다.

## 누구에게 맞나

- 백엔드가 준비되기 전에 화면부터 붙여 봐야 하는 사람, 강의나 시연에서 API 예제가 필요한 사람.

## 5분 안에 시작하기

```
# apeeye.ibr0r.com에서 Playground를 열고 users 같은 컬렉션 이름을 하나 적는다. 위에 뜨는 주소를 그대로 호출하면 된다.
```

## 주의할 점

- 탭이 열려 있는 동안에만 주소가 살아 있다. 계정이 없어서 작업 공간 주소를 아는 사람은 누구나 읽고 쓸 수 있으니 실제 자료는 넣지 않는다. 별이 한 자리인 초기 프로젝트다.
