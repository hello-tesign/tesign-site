## TESIGN TAKE

음성 작업을 외부 서비스 없이 내 컴퓨터에서 끝내고 싶다면 먼저 볼 만한 앱입니다.

## 왜 볼 만한가

목소리를 다루는 작업은 대개 원본 파일을 외부 서비스에 올리는 것부터 시작합니다. voicestudio는 복제·더빙·받아쓰기·오디오북 제작을 전부 로컬에서 돌리는 쪽을 택해, 음성 파일이 기기 밖으로 나가지 않습니다. 저장소 설명 기준 646개 언어를 다루고, Python으로 쓰였으며 AGPL-3.0으로 공개돼 있습니다. 직접 설치해 쓰는 형태라 실행 환경은 준비해야 합니다.

## 이걸로 무엇을 만들 수 있나

- 외부 업로드 없이 사내에서 끝내는 음성 더빙 공정
- 회의 녹음을 자동으로 받아쓰는 사내 기록 도구
- 원고를 브랜드 목소리로 읽히는 오디오북 제작 라인

## 누구에게 맞나

- 영상 제작자 — 더빙·자막 작업에 음성 파일을 외부에 올리기 싫을 때
- 1인 사업자 — 안내 음성·오디오북을 직접 만들어야 할 때
- 개발자 — 로컬 음성 API(OpenAI 호환)를 제품에 붙이려 할 때
