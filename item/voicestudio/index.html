왜 볼 만한가

목소리를 다루는 작업은 대개 원본 파일을 외부 서비스에 올리는 것부터 시작합니다. voicestudio는 복제·더빙·받아쓰기·오디오북 제작을 전부 로컬에서 돌리는 쪽을 택해, 음성 파일이 기기 밖으로 나가지 않습니다. 저장소 설명 기준 646개 언어를 다루고, Python으로 쓰였으며 AGPL-3.0으로 공개돼 있습니다. 직접 설치해 쓰는 형태라 실행 환경은 준비해야 합니다.

이걸로 무엇을 만들 수 있나

  • 외부 업로드 없이 사내에서 끝내는 음성 더빙 공정
  • 회의 녹음을 자동으로 받아쓰는 사내 기록 도구
  • 원고를 브랜드 목소리로 읽히는 오디오북 제작 라인

5분 안에 시작하기

# 릴리스 페이지에서 macOS DMG · Windows MSI · Linux AppImage 내려받기
# 첫 실행 때 Python 환경과 기본 모델을 자동으로 받습니다. 소스 실행은:
$ git clone https://github.com/debpalash/VoiceStudio.git
$ cd VoiceStudio
$ bun install
$ bun run desktop

주의할 점

  • 활성 베타이며 데스크톱 앱은 Electron으로 다시 만드는 중입니다
  • 기본 모델 가중치는 CC-BY-NC — 생성 음성의 상업 이용은 모델 약관 확인
