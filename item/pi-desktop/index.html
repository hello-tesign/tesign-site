왜 볼 만한가

코딩 에이전트를 터미널에서만 쓰면 설정과 플러그인 관리가 사람마다 제각각이 됩니다. pi-desktop은 이를 데스크톱 앱으로 묶어, Electron 화면 아래 Rust 호스트 코어와 에이전트 하네스를 두고 플러그인을 직접 설치해 붙이게 합니다. 로컬 우선으로 동작하고 MCP를 지원하며 LGPL-3.0으로 공개돼 있습니다.

이걸로 무엇을 만들 수 있나

  • 팀원 모두 같은 설정으로 쓰는 사내 에이전트 앱
  • 필요한 기능만 골라 붙이는 개인 플러그인 구성
