왜 볼 만한가

컴퓨터 앞이 아닐 때 급하게 고칠 일이 생기면 방법이 마땅치 않다. Acode는 안드로이드에서 HTML·CSS·자바스크립트를 고쳐 곧바로 브라우저로 확인하게 하고, 내장 터미널과 SFTP·SSH 연결로 서버 파일까지 손보게 한다.

이걸로 무엇을 만들 수 있나

  • 자바스크립트로 만든 안드로이드 앱이다. 여러 언어의 문법 표시, 내장 자바스크립트 콘솔, 알파인 리눅스 기반 터미널, S/FTP·SSH, 커뮤니티 플러그인, 여러 나라 말을 지원한다. 구글 플레이와 F-Droid, 깃허브에서 받을 수 있다.

누구에게 맞나

이동 중에 사이트를 고쳐야 하는 사람, 태블릿으로 공부하는 사람, 노트북 없이 서버를 잠깐 손봐야 하는 사람.

5분 안에 시작하기

# 구글 플레이나 F-Droid에서 설치한 뒤 파일 하나를 열어 본다.

주의할 점

  • 소스는 MIT로 공개돼 있지만 공식 사이트에 유료 Pro 안내가 따로 있다. 안드로이드 전용이고, 작은 화면에서 긴 코드를 다루는 일은 역시 편하지 않다.
