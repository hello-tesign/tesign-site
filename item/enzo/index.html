왜 볼 만한가

ChatGPT류 서비스는 편하지만 요금이 쌓이고 대화가 남의 서버에 남는다. ENZO는 오픈라우터·구글 AI 스튜디오·NVIDIA NIM 같은 곳의 내 API 키를 직접 넣어 쓰는 채팅·에이전트 작업공간이다. 요청은 내 브라우저에서 골라 둔 제공사로 바로 가고, 중간에서 수수료를 떼는 계정이나 구독이 없다.

이걸로 무엇을 만들 수 있나

  • 도커 한 번이면 설치가 끝나고(docker compose up -d), 설치 없이 써 보고 싶으면 구글 코랩 노트북으로도 5분이면 뜬다. 300개 이상 모델 카탈로그, 작업을 시키면 실행 매뉴얼을 스스로 써 내려가는 에이전트, 74개 내장 스킬을 갖췄고 API 키는 암호화해 브라우저에 저장한다.

누구에게 맞나

여러 AI 모델을 요금 걱정 없이 오가며 비교해 보고 싶은 사람, 대화 기록을 내 손에 두고 싶은 사람.

5분 안에 시작하기

# README의 "Open in Colab" 버튼을 눌러 노트북을 전체 실행하는 것이 가장 쉽다 — 직접 설치하려면 저장소를 받아 docker compose up -d 후 localhost:5001을 연다.

주의할 점

  • 각 AI 제공사의 API 키를 직접 준비해야 쓸 수 있다(오픈라우터·구글 AI 스튜디오 등 일부는 무료 한도 제공). 코랩으로 쓰면 무료 세션이 최대 12시간 정도로 제한된다.
