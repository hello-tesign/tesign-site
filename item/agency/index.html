왜 볼 만한가

에이전트에 일을 시키려면 매번 무엇을 할지 먼저 찾아 적어 줘야 합니다. Agency는 순서를 바꿔, 에이전트가 저장소·지원 티켓·메시지에서 쓸 만한 일을 스스로 찾아 고침·답장·아이디어를 카드로 준비하고, 사람은 보내기·적용·병합만 결정합니다. Node.js로 로컬에서 띄우는 1인용 앱이며 인증 없는 경로가 있어 localhost 밖으로 내놓지 말라고 README가 못 박습니다. 라이선스는 README에 표기돼 있지 않습니다.

이걸로 무엇을 만들 수 있나

  • 지원 티켓에서 고칠 것을 골라 PR과 답장까지 준비하는 사내 큐
  • 아웃리치 초안을 카드로 받아 승인만 하는 검토대
  • 승인 정책 파일을 팀 규칙에 맞게 고쳐 쓰는 운영 지침

5분 안에 시작하기

$ git clone https://github.com/browser-use/agency.git
$ cd agency
$ npm ci
$ npm run dev -- --hostname localhost --port 3100
# Node.js 22.13+ 필요 · 브라우저에서 http://localhost:3100 열기
# 인증 없는 1인용 앱이라 0.0.0.0이나 공개 터널로 노출 금지

주의할 점

  • README에 라이선스가 표기돼 있지 않습니다
  • 인증 없는 경로가 있어 localhost 밖으로 노출하면 안 됩니다
  • 히어로 카드는 README가 밝힌 가상 예시입니다
