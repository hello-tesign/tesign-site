## TESIGN TAKE

기능을 늘리는 대신 "빨리 열리고 멈추지 않는다"에 집중한 편집기다. 로그를 자주 들여다보는 자리라면 차이가 바로 느껴진다.

## 왜 볼 만한가

로그나 데이터 파일이 수백 메가를 넘어가면 보통 편집기는 열다가 멈춘다. miu는 파일 전체를 한 번에 읽지 않고 메모리 맵 방식으로 다루기 때문에 큰 파일도 바로 열리고, C++와 Win32로 직접 만들어 동작이 가볍다.

## 이걸로 무엇을 만들 수 있나

- DirectWrite로 글자와 컬러 이모지를 그린다. 정규식 검색과 치환(대소문자·단어 단위 구분), 멀티 커서, 사각 선택, 무제한 실행 취소, 다크 모드, F1 도움말을 갖췄다. 문자 인코딩 판별에는 구글 compact_enc_det를 쓴다. 완성된 실행 파일은 깃허브 Releases에서 받는다.

## 누구에게 맞나

- 큰 로그·데이터 파일을 자주 여는 사람, 가벼운 메모장 대체가 필요한 윈도우 사용자.

## 5분 안에 시작하기

```
# 깃허브 Releases에서 실행 파일을 내려받아 바로 실행한다. 설치 과정이 따로 없다.
```

## 주의할 점

- 설명과 도움말이 일본어 중심이다. 윈도우 위주로 만들어졌고(저장소에는 맥·iOS 대상도 적혀 있다), 직접 빌드하려면 인코딩 판별 라이브러리를 먼저 준비해야 한다.
