## TESIGN TAKE

격리 도구는 보통 쓰기 번거로워 결국 안 쓰게 되는데, 평소 환경을 최대한 유지해 '안 쓸 이유'를 줄였다는 점이 다르다.

## 왜 볼 만한가

남이 만든 프로그램이나 코딩 에이전트를 내 계정으로 그대로 돌리면, 의존성 하나만 오염돼도 시스템 전체가 위험해진다. Drop은 파이썬 가상환경처럼 쉽게 만들고 버리는 격리 환경을 제공한다.

## 이걸로 무엇을 만들 수 있나

- 새 운영체제를 까는 대신 지금 쓰는 배포판을 그대로 쓰므로 설치해 둔 프로그램을 샌드박스 안에서도 쓸 수 있고, 사용자 이름도 유지되며 골라 둔 설정 파일만 읽힌다. drop init으로 환경을 만들고 drop run으로 들어간다.

## 누구에게 맞나

- 코딩 에이전트나 출처가 불분명한 도구를 리눅스에서 돌리는 개발자.

## 5분 안에 시작하기

```
# droprun.sh의 설치 안내를 따른 뒤, 프로젝트 폴더에서 drop init과 drop run을 실행한다.
```

## 주의할 점

- 리눅스 전용이다. 골라 둔 설정 파일은 샌드박스 안에서도 읽히므로, 무엇을 열어 둘지 설정을 확인하고 쓸 것.
