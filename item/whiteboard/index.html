왜 볼 만한가

에이전트가 코드를 대량으로 바꾸면 무엇이 어떻게 이어지는지 글만으로는 따라가기 어렵다. Whiteboard는 사람과 에이전트가 같은 캔버스에서 구조를 그려 가며 설계하게 한다. 에이전트가 흐름도를 그리고, 사람이 '캐시 없이 다시 그려 봐'처럼 말로 고쳐 달라고 할 수 있다.

이걸로 무엇을 만들 수 있나

  • 맥과 페도라용 데스크톱 앱이다. Claude Code·Codex 같은 코딩 에이전트를 시작 화면에서 연결하면, 에이전트가 SDK로 앱 안의 캔버스에 그림을 그린다. 화면에는 설명 문서, 흐름도, 해당 코드가 나란히 놓인다.

누구에게 맞나

코딩 에이전트와 함께 큰 변경을 설계·검토하는 개발자와 팀.

5분 안에 시작하기

# install.dev.fast에서 앱을 받아 열고, 시작 화면에서 Claude Code나 Codex를 연결한다.

주의할 점

  • README 기준 설치 파일은 맥과 페도라용만 있다. 코딩 에이전트가 따로 있어야 쓸모가 생긴다.
