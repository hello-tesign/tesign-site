## TESIGN TAKE

웹 방식과 네이티브 방식을 한 앱 안에서 섞어 쓸 수 있다.

## 왜 볼 만한가

데스크톱 앱을 만들려면 크기가 큰 웹 틀을 통째로 싣는 경우가 많다. MyGo는 운영체제에 이미 있는 웹뷰를 쓰거나 GPU로 직접 그리는 화면을 써서, 작고 메모리를 덜 쓰는 앱을 만들게 한다고 밝힌다.

## 이걸로 무엇을 만들 수 있나

- cgo 없이 순수 Go라서 어느 컴퓨터에서든 모든 플랫폼용으로 빌드할 수 있다. 웹 화면은 Go 코드에서 만든 타입 있는 TypeScript 클라이언트로 Go 함수를 부르고, 네이티브 화면용 위젯·레이아웃·접근성도 갖췄다. 창, 메뉴, 트레이, 알림, 단축키와 설치 파일 제작, 서명, 자동 업데이트까지 넣었다.

## 누구에게 맞나

- Go로 가벼운 데스크톱 앱을 만들고 싶은 개발자.

## 5분 안에 시작하기

```
# 웹사이트 안내대로 bunx mygo-cli init my-app 명령으로 새 프로젝트를 만든다.
```
