## TESIGN TAKE

사람이 모션 디자이너에게 주문하듯 원하는 영상을 말로 설명하는 사용법이다.

## 왜 볼 만한가

웹 페이지를 브라우저에서 영상으로 바꾸는 방식은 렌더링이 오래 걸린다. fframes는 영상을 러스트와 SVG로 쓰고 GPU로 그려, 128초짜리 영상을 36초에 뽑았다고 밝힌다.

## 이걸로 무엇을 만들 수 있나

- 에이전트용 스킬을 한 번 추가하면 에이전트가 설치, 프로젝트 생성, 모션 설계, 소리 배치, 확인까지 이어서 한다. 에이전트는 영상을 볼 수 없으므로, 프레임 점검(inspect), 대표 프레임 모음(strip) 같은 명령으로 영상을 읽을 수 있는 PNG와 숫자로 바꿔 준다.

## 누구에게 맞나

- 코딩 에이전트로 영상을 만들고 싶은 개발자.

## 5분 안에 시작하기

```
# npx skills add https://fframes.studio 로 스킬을 추가하고, 에이전트에게 원하는 영상을 설명한다.
```

## 주의할 점

- 러스트 기반이며 API가 길고 명시적이라는 점을 README가 스스로 밝힌다. GPU가 필요한지, 지원 운영체제가 무엇인지는 README만으로는 확인하지 못했다.
