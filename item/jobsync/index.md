## TESIGN TAKE

설치하기 전에 공개 데모에서 화면을 전부 둘러볼 수 있다는 점이 크다. 구직 도구는 대개 가입부터 시키는데, 이쪽은 내 서버에 올려 두고 쓰는 쪽을 택했다.

## 왜 볼 만한가

지원 현황을 스프레드시트에 적다 보면 어디까지 했는지 금방 흐려진다. JobSync는 지원 기록·이력서·면접 질문을 한 화면에 모으고, 이력서 검토나 공고 매칭 같은 AI 기능을 내 컴퓨터의 Ollama로도 돌릴 수 있게 해 둔다. 이력서가 밖으로 나가지 않는다.

## 이걸로 무엇을 만들 수 있나

- 도커로 설치한다. 내려받아 docker compose up을 하고 localhost:3737에서 계정을 만들면 끝이다. 지원 현황판과 달력, 이력서 보관이 있고 PDF·워드 이력서를 불러오면 경력·학력·연락처를 항목별로 나눠 준다. 다시 내보낼 때는 서식을 갖춘 PDF 두 종류 중 고른다. MCP 서버가 들어 있어 클로드 데스크톱 같은 도구에서 채팅으로 공고를 넣을 수도 있다.

## 누구에게 맞나

- 여러 회사에 동시에 지원 중이라 진행 상황이 헷갈리는 사람. 이력서를 회사마다 조금씩 고쳐 쓰는 사람.

## 5분 안에 시작하기

```
# demo.jobsync.ca에서 실제 화면을 먼저 보고, 쓸 만하면 도커가 있는 컴퓨터나 서버에 올린다.
```

## 주의할 점

- 설치에 도커가 필요하고, 첫 실행은 앱을 빌드하느라 몇 분 걸린다. AI 기능은 내 컴퓨터의 모델을 쓰거나 외부 서비스 키를 직접 넣어야 동작한다. 원격 서버에 올린다면 시간대(TZ)를 반드시 맞춰야 기록 시각이 어긋나지 않는다.
