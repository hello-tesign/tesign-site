## TESIGN TAKE

It states early what does not travel: the conversation moves, while system instructions and project files stay behind. Better to know that up front.

## WHY IT MATTERS

Switching tools usually means explaining everything again. txcript converts a stored session into the target agent’s own format, writes a new native session and opens it in the recorded working directory. The source session is kept.

## BUILD FROM THIS

- A Rust CLI and library. Download a binary for macOS, Linux or Windows, or install from source. It reads and writes Claude Code, Codex, OpenCode, Cursor, Grok, Antigravity and more, and anything unsupported can go through its interchange JSON. An MCP mode exposes past sessions read-only, and there are Rust and JavaScript packages. The documentation includes Korean.

## WHO IT'S FOR

- Developers who move between Claude Code, Codex and the like, and anyone archiving or searching past sessions.

## START IN 5 MINUTES

```
# Grab a binary from Releases, then run continue with a session id and the agent you want to carry on in.
```

## CAVEATS

- Anything the source never recorded, or the destination cannot represent, is lost in conversion. The new tool supplies its own system instructions and tools, and project files must be moved separately. Reading Claude Chat and ChatGPT relies on private web APIs and an existing login. The maker also sells a paid service.
