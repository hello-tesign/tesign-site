A Claude Code onboarding skill walks through setup and deployment.

## WHY IT MATTERS

Keeping team code on infrastructure you control usually means running GitHub Enterprise or GitLab. GitOrange keeps the familiar GitHub interface with no VM, disk or git daemon to look after.

## BUILD FROM THIS

- Repositories live in Cloudflare Artifacts and everything else in D1. Your existing .github/workflows files run on Cloudflare Containers with the same syntax, so typical build-and-test workflows work unchanged.

## WHO IT'S FOR

- Small teams on Cloudflare who want to control their own code hosting.

## START IN 5 MINUTES

# Follow the README Quickstart. It needs a Cloudflare Workers Paid plan, a domain for email sending and Node.js 20+.

## CAVEATS

- Needs a paid Cloudflare plan (a few dollars a month), relies on Artifacts which is in open beta, and does not yet support repository secrets.
