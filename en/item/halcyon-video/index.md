## TESIGN TAKE

A one-person project that turns choosing a film back from scrolling a list into browsing a shop.

## WHY IT MATTERS

Picking a film has become endless poster scrolling; Halcyon turns that catalog into a store you walk into. Libraries become aisles, genres become sections, and you pull a case, read the back and check out at the counter, driving it with a keyboard, gamepad, TV remote or phone. The hosted demo opens with no signup, media server or API key, and a local copy starts with start.cmd, start.command or start.sh, or the ghcr.io Docker image.

## BUILD FROM THIS

- Set up a living-room HTPC kiosk (install script included) or a 2.5D screen for a Raspberry Pi, and repaint the store with the Brand Editor's name, colours and emblem so it becomes your own household video shop.

## WHO IT'S FOR

- Jellyfin, Plex or Emby self-hosters — a couch-friendly browsing front end for the TV
- HTPC and Raspberry Pi owners — kiosk mode and the 2.5D fallback
- Retro game collectors — a games department fed by RomM

## START IN 5 MINUTES

```
# git clone https://github.com/halcyon-video/halcyon-video
# cd halcyon-video
# npm install
# npm run dev
# # Or Docker: docker run -d --name halcyon --network host --restart unless-stopped ghcr.io/halcyon-video/halcyon-video
```

## CAVEATS

- Licence GPL-3.0. The public demo opens with no signup, server or API key but playback is disabled there, and shelving your own files requires Jellyfin, Plex or Emby (there is no folder scanner).
- The 3D room renders in the browser; the renderer scales to the hardware, and weak devices can fall back to 2.5D mode or Remote Play. A desktop bundle and the Apple TV client are not shipped, and Roku is unsupported.
- A single-owner project that does not accept pull requests (bug reports only), with an optional Ko-fi tip jar inside the store.
