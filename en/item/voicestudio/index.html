WHY IT MATTERS

Working with voice usually starts by uploading the original recording to somebody else's service. voicestudio keeps cloning, dubbing, dictation, transcription and audiobook production on the machine in front of you, so the audio never leaves it. The repository states coverage of 646 languages; it is written in Python and published under AGPL-3.0. It is self-hosted, so the runtime environment is yours to prepare.

BUILD FROM THIS

  • A dubbing workflow that stays in-house with no external upload
  • An internal tool that transcribes meeting recordings
  • An audiobook line that reads your scripts in a brand voice

WHO IT'S FOR

Video maker
dubs and transcribes without uploading audio elsewhere
Solo business
needs voice prompts or audiobooks made in-house
Developer
wants a local, OpenAI-compatible speech API

START IN 5 MINUTES

# Download the macOS DMG, Windows MSI or Linux AppImage from Releases
# First launch fetches a Python env and the default model. From source:
$ git clone https://github.com/debpalash/VoiceStudio.git
$ cd VoiceStudio
$ bun install
$ bun run desktop

CAVEATS

  • Active beta; the desktop app is being rewritten on Electron
  • Default model weights are CC-BY-NC: check model terms before commercial use
  • Intel Macs cannot run the local backend; a remote backend is required
