WHY IT MATTERS

Once notes pile up, remembering what you wrote and how one note connects to another gets hard. hibi keeps the raw Markdown and the formatted view side by side, and shows the current note’s connections as both a graph and a list on the right.

BUILD FROM THIS

  • An Electron desktop app that opens a file or a folder as a workspace, with a formatting toolbar (bold, italic, tables, headings), a cmd+K (ctrl+K on Windows/Linux) command palette, version history, and import/export. It is released under AGPL-3.0 and takes addons.

WHO IT'S FOR

People who keep notes and drafts in Markdown, and anyone who wants to see how notes link up.

START IN 5 MINUTES

# Install a nightly build from GitHub Releases and open a folder as a workspace.

CAVEATS

  • Only alpha nightly builds exist, so you may see an ad-hoc signing warning, and the repository itself says to back up your notes first. It is AGPL-3.0, so offering a modified version as a service means releasing that source too.
