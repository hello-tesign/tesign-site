WHY IT MATTERS

Pomodoist organizes tasks across inbox, today, upcoming, projects, timeline, kanban and a priority matrix, starts a Pomodoro session from any task and shows weekly focus-time trends in built-in reports. Built in Flutter/Dart, it offers the same workspace on macOS, iOS/iPadOS, Linux, Windows and the web (app.pomodoist.com), with a Docker Compose self-hosting guide covering PostgreSQL, Auth, REST and Realtime. The README lists Android among supported platforms, but the official site shows it as planned for September–October 2026.

BUILD FROM THIS

  • Point an MCP client at your own instance's endpoint (/functions/v1/pomodoist-mcp) so an AI assistant can read and add your tasks. The repository also includes the Telegram Mini App and Chrome extension code, which you can adapt for your own use.

START IN 5 MINUTES

# git clone https://github.com/Kabanya/Pomodoist.git
# cd Pomodoist
# make -C server setup
# make -C server up
# # open http://localhost:58080

CAVEATS

  • AGPL-3.0-only (copyright FinchForge LLC): if you modify it and offer it as a service, you must release the source.
  • Self-hosting is free but needs Docker Compose v2, make, openssl, curl and a practical minimum of 4 GB RAM and 40 GB disk.
  • The hosted Pro subscription and lifetime purchase are paid (prices per the App Store). Android is in the README's supported list but the official site shows it as planned for September–October 2026, and the site FAQ says iOS and iPadOS are under review.
