WHY IT MATTERS

Architecture drawings go stale quickly, and every correction means opening the drawing tool again. archify comes as a skill for coding agents, so architecture, workflow, sequence, data-flow and lifecycle diagrams get produced next to the code. The output is a single self-contained HTML file you can open or export as is. Published under MIT.

BUILD FROM THIS

  • Onboarding-document diagrams that explain the repository layout
  • A one-page system flow diagram for a client proposal
  • An architecture page redrawn with every release

WHO IT'S FOR

Backend developer
keeps onboarding diagrams current
Tech consultant
needs a system flow diagram for a proposal
Tech lead
shows architecture before and after a PR

START IN 5 MINUTES

$ npx skills add tt-a1i/archify -g
# To try without installing (Codex example):
$ npx skills use tt-a1i/archify@archify --agent codex
# Describe the system in the agent chat and ask Archify to draw it

CAVEATS

  • Needs an agent host (Cursor, Claude Code, Codex, OpenCode) plus Node.js
  • Sends an update-check request by default; an env var disables it
  • Mermaid import and WYSIWYG editing are stated as out of scope
