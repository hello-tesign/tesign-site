WHY IT MATTERS

Run a coding agent only in the terminal and everyone ends up with their own settings and plugins. pi-desktop packages it as a desktop app: an Electron surface over a Rust host core and an agent harness, with plugins the user installs. It works local-first, supports MCP, and is published under LGPL-3.0.

BUILD FROM THIS

  • An internal agent app everyone on the team runs with one setup
  • A personal plugin set carrying only the features you use

WHO IT'S FOR

Developer
reviews diffs and command output on screen, not in a terminal
Team lead
gives everyone the same agent app and setup
Local-model user
connects Ollama or LM Studio to an agent

START IN 5 MINUTES

# Download the macOS, Windows or Linux build from GitHub Releases
# Open Settings → Model configuration and add a provider and credentials
# Add a local project folder from the sidebar, then pick Agent, Plan or Goal

CAVEATS

  • Early preview: APIs, extension interfaces and behaviour may still change
  • macOS builds are unsigned by default; first launch may need a quarantine step
  • Linux needs glibc 2.35 or newer (Ubuntu 22.04 and later)
