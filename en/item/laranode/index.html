WHY IT MATTERS

cPanel and Plesk do the job but bill every month. LaraNode puts the same kind of panel on a server you already pay for, with no licence fee — aimed at the one or two boxes that are awkward to run from a terminal alone.

BUILD FROM THIS

  • Built with Laravel (PHP); minimum is Ubuntu 24.04, 1 vCPU, 2 GB RAM and 10 GB disk. It covers site creation, one-click Let’s Encrypt SSL, a file manager written from scratch, MySQL databases, per-site PHP 7.4–8.5, UFW firewall rules and live CPU, memory and network stats. Backups — whole accounts, files or databases — go locally, to S3 or over SFTP, on demand or on a retention schedule, and accounts have admin and user roles.

WHO IT'S FOR

Solo operators and small teams running sites on a VPS or two, and anyone trying to drop a hosting panel licence.

START IN 5 MINUTES

# Look around demo.laranode.com, then run the install command on a fresh Ubuntu server.

CAVEATS

  • It installs on a fresh VPS, not on top of a server already in use, and assumes Ubuntu with Apache, MySQL and PHP. The demo mode must never be switched on where real sites and accounts are managed.
