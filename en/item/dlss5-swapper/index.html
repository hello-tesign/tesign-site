WHY IT MATTERS

Swapping DLSS files by hand is an easy way to lose originals, and which games it works in is trial and error. DLSS 5 Swapper scans Steam, Epic, GOG and Game Pass folders, manages install, restore and backup per game, and routes games without DLSS through Feeder and old APIs through dgVoodoo. An F8 overlay moves the sliders in-game, and a community page shows reports from people with your card. Free, MIT, Windows 10/11 only; for anti-cheat games it warns of crashes or bans.

BUILD FROM THIS

  • A personal routine that applies and reverts one setting across a library
  • A community report of results per game and graphics card
  • An experiment putting neural rendering on old DX9 and emulator titles

WHO IT'S FOR

PC gamer
wants DLSS 5 across several games on an RTX card
Emulator user
wants to upscale old console titles

START IN 5 MINUTES

# Download the Windows installer or the portable build from the latest release
# Verify the checksum with SHA256SUMS.txt on the same page
# The Feeder route needs Visual C++ runtimes (x64, plus x86 for 32-bit games)

CAVEATS

  • Anti-cheat games risk crashes or bans; the app warns but never bypasses
  • The bundled OptiScaler model runs only on RTX 50-series cards
  • No Linux binaries; Proton is experimental community source only
