WHY IT MATTERS

It gathers the utilities Mac users usually buy one by one (per-app volume, system monitor, app switcher, window snapping, clipboard history, uninstaller) behind a single menu bar icon, with no account, telemetry or subscription. The Features page installs and uninstalls whole features; what you remove stops loading and spends no CPU or memory. First committed in June 2026, it reached the front of GitHub trending in three days per the README and sits at 18,627 stars.

BUILD FROM THIS

  • The GPL Swift source is a reference for building your own take on a single feature, such as per-app audio routing or window snapping. The name, icon and look are covered separately by TRADEMARKS.md, so a fork needs its own identity.

WHO IT'S FOR

Mac users
per-app volume, window snapping and clipboard history in one app
People paying for several utilities
a no-subscription replacement
Swift developers
a reference for a modular menu bar app

START IN 5 MINUTES

# brew install --cask vorssaint
# # or download the disk image from the releases page and drag Vorssaint into Applications
# # remove: brew uninstall --cask vorssaint
# # remove completely, including settings and permissions: ./Tools/uninstall.sh

CAVEATS

  • Licence GPL-3.0 (README: GPL-3.0-or-later); the name, logo and look are covered separately by TRADEMARKS.md.
  • Apple Silicon Macs on macOS 14 Sonoma or newer only. Features need macOS permissions such as Accessibility and Screen Recording, each optional.
  • Free, no account or analytics. Latest release v3.3.5 as of 2026-09-15.
