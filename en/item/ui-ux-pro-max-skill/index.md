## TESIGN TAKE

With over 130,000 stars, it is one of the most widely used design skills right now.

## WHY IT MATTERS

Hand screens to an AI coding tool and you tend to get the same default look. UI UX Pro Max packs UI styles, colour palettes, font pairings, chart types and UX guidelines into a searchable reference the agent draws on for the screen it is building.

## BUILD FROM THIS

- A skill that plugs into Claude Code, Cursor, Windsurf, Antigravity, GitHub Copilot, Kiro, Codex and Qoder. The official site shows demo screens built across stacks and styles, and the README has a Korean version.

## WHO IT'S FOR

- Developers and solo founders who build web and app screens with AI coding tools.
