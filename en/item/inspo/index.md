## TESIGN TAKE

It makes its case with two screens built from the same brief. Whether that gap shows up in your own work is something to test rather than take.

## WHY IT MATTERS

Hand a screen to an agent and you get the function without the taste. Inspo captures 2,320 pages across 832 live sites on desktop and mobile, records their palettes, fonts and structure, and hands them to the agent over MCP while it works.

## BUILD FROM THIS

- An MCP server. Every site carries a design document extracted from its DOM — semantic palette roles, type ramp, spacing scale, CSS variables — and 68 canonical components (heroes, pricing, footers, navs) come as copy-pasteable JSX. Fifteen tools expose it all.

## WHO IT'S FOR

- People building UI with Claude Code or Cursor, and teams shaping product screens without a designer.

## START IN 5 MINUTES

```
# Follow inspomcp.dev to register it as an MCP server in your agent, then build one screen with it.
```

## CAVEATS

- The library is made of other companies’ live sites: it is reference material, not something to copy wholesale. The project is new and still moving.
