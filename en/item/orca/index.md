## TESIGN TAKE

A workbench worth trying once you run more than one coding agent at a time and the terminal stops scaling.

## WHY IT MATTERS

Once several coding agents run at the same time, terminal windows and working folders start to tangle. Orca gathers them into one agent development environment, where parallel agents can be attached and detached from a single place. Agents run on the subscription you already pay for, and it is available on desktop, mobile and a remote runtime. Published under MIT.

## BUILD FROM THIS

- An internal dev environment with several agents attached at once
- A mobile window onto work in progress while away from the desk
- A shared team agent slot on a remote runtime

## WHO IT'S FOR

- Solo developer — runs several agents in separate worktrees
- Team lead — reviews agent work next to PRs and issues
- On-the-go developer — checks progress and replies from a phone

## START IN 5 MINUTES

```
# Download the macOS, Windows or Linux build from onOrca.dev
# macOS (Homebrew):
$ brew install --cask stablyai/orca/orca
# Arch Linux (AUR):
$ yay -S stably-orca-bin
# Mobile: iOS App Store, TestFlight or the Android APK, then pair with the desktop
```

## CAVEATS

- Bring your own agents (Claude Code, Codex, etc.) and their subscriptions
- Anonymous usage telemetry is collected; the docs explain how to opt out
- Ships daily, so features and screens change often
