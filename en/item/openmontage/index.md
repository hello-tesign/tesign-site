## TESIGN TAKE

An experiment in handing a whole video pipeline to a coding agent, notable for a free path that needs no keys.

## WHY IT MATTERS

One video pulls in a different tool for planning, subtitles, dubbing and editing. openmontage moves that chain into skills and pipelines a coding assistant can drive from one place. The repository lists 12 production pipelines, over 100 tools and more than 700 skill and production-knowledge files. It is written in Python and published under AGPL-3.0, so the terms depend on how you use it.

## BUILD FROM THIS

- An in-house line that drafts product videos automatically
- A multilingual release flow that finishes subtitles and dubbing
- A repeatable production run for social clips

## WHO IT'S FOR

- Marketer — drafts a product explainer video quickly
- Solo creator — makes script, narration and captions in one pass
- Developer — experiments with video automation from a coding agent

## START IN 5 MINUTES

```
# Needs Python 3.10+, FFmpeg, Node.js 18+ and an AI coding assistant
$ git clone https://github.com/calesthio/OpenMontage.git
$ cd OpenMontage
$ make setup
# Open the project in your coding assistant and describe the video
```
