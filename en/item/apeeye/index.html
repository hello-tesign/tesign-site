WHY IT MATTERS

Building the screen before the backend exists usually stalls. In Apeeye you name a collection and it is a live endpoint immediately — callable from your app, from curl or Postman, or from a teammate’s machine.

BUILD FROM THIS

  • Records live only in your browser’s IndexedDB; the server stores nothing. A stateless relay forwards each request over a WebSocket to your open tab, which answers from IndexedDB. GET, POST, PUT, PATCH and DELETE all work with sensible status codes, and a whole workspace exports and imports as JSON. You can also clone it and run it locally.

WHO IT'S FOR

Front-end developers waiting on a backend, and anyone who needs a throwaway API for a demo or a class.

START IN 5 MINUTES

# Open the Playground at apeeye.ibr0r.com, add a collection such as users, and call the workspace URL shown at the top.

CAVEATS

  • The endpoints answer only while a tab is open. There are no accounts, so anyone with the workspace URL can read and write it — keep real data out. It is an early project with single-digit stars.
