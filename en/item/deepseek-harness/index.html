WHY IT MATTERS

An agent harness gets heavier with every capability added, and features nobody asked for come along with them. DeepSeek Harness takes the position that everything is a plugin, so only what is needed gets attached. It is written in TypeScript, published under MIT, and documented on its own homepage. The repository description is a single line, so the supported scope has to be read from the docs.

BUILD FROM THIS

  • An in-house agent setup carrying only the capabilities you need
  • A shared set of internal plugins for the team

WHO IT'S FOR

Agent developer
wants to compose a harness from plugins
Platform engineer
builds a shared plugin set for a team

START IN 5 MINUTES

# With Node.js installed:
$ npx @deepseek-ai/dsh web
# The web UI opens at http://127.0.0.1:3080

CAVEATS

  • A developer preview; the README states there will be breaking changes
  • It asks you to read the repository's safety notice before running it
