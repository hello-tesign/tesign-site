## TESIGN TAKE

It runs a pinned DSH unchanged and adds the window, tray and updater as plugins of the same kind — and it says plainly that it is not a DeepSeek product.

## WHY IT MATTERS

The most-starred repository in this month's list (26,127 stars as of 13 Sep 2026), chosen to stand for ten DeepSeek Harness (DSH) ecosystem repositories. It runs DSH's local Web UI, Host service and plugin system at a pinned upstream version, unchanged, and adds a window, tray, terminal, updater and work profiles as an installable app (Windows x64 NSIS installer, macOS Universal DMG). The desktop shell is itself a Cordis-based DSH plugin, and a plugin marketplace (DSH Community Market) is built in. The README states it is an independent community project with no affiliation, partnership or endorsement from DeepSeek.

## BUILD FROM THIS

- With the Desktop plugin API you can write desktop plugins that switch work profiles or install and remove plugins, and you can feed your own plugin directory into the built-in market as a data source that follows the public schemas.

## WHO IT'S FOR

- People who want DeepSeek Harness without terminal or Node.js setup — install and run
- Existing DSH users — tray, work profiles and the built-in plugin market
- Plugin developers — the Desktop plugin API and market data sources

## START IN 5 MINUTES

```
# 1. Windows x64: download the installer from https://www.dshdesktop.cn/api/downloads/windows and run the NSIS installer
# 2. macOS Universal: download the DMG from https://www.dshdesktop.cn/api/downloads/mac, open it and drag DSH Desktop into Applications
# 3. Run from source: git submodule update --init --recursive
# 4. corepack yarn install --immutable
# 5. corepack yarn dev
```
