WHY IT MATTERS

Ask an agent for a design and the result stays stuck in the chat, hard for a person to refine. Design Studio AI keeps web layouts, slides, reports, wireframes, 3D scenes and timeline videos in one versioned document that people and agents edit in turn, by chat or a manual editor. Agents connect over REST, MCP and a CLI, exports include HTML, PDF, PowerPoint and GLB, and generation uses outside providers with your own keys. Hosted studio or Docker self-host; MIT.

BUILD FROM THIS

  • A proposal-deck flow where the agent drafts and a designer finishes
  • An internal workspace tying screen mock-ups to one design system
  • A small-studio pipeline keeping video and 3D scenes in the same document

WHO IT'S FOR

Solo designer
wants agent drafts they can finish by hand
Agent builder
needs an MCP or CLI path in and out of designs
Small team
keeping slide, screen and video mock-ups in one place

START IN 5 MINUTES

# Hosted: start right away at studio.agentkit.best (nothing to install)
# Self-host: set ENCRYPTION_KEY and APP_URL first (Node.js 24+ or Docker)
$ docker compose up --build -d
# The container binds to 0.0.0.0:8787 · use an HTTPS proxy if internet-facing

CAVEATS

  • Generation needs your own API keys and provider accounts
  • Google Slides export and similar were not live-verified, per the README
  • The CLI is not on npm; install from the release tarball
