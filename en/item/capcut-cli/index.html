WHY IT MATTERS

CapCut and JianYing normally mean clicking through the timeline by hand. capcut-cli reads and writes the local draft file (draft_content.json) directly, so cutting, captioning and speed changes become a one-line command or script — and the result still opens in CapCut with every track editable.

BUILD FROM THIS

  • A zero-dependency Node.js CLI that works directly on the local draft store — no server, no upload. Whisper and FFmpeg plug in optionally for captions and rendering, and it installs as an agent skill for Claude Code, Codex and others.

WHO IT'S FOR

Editors churning out short-form video in CapCut/JianYing at volume, and anyone who wants to script captioning and cutting.

START IN 5 MINUTES

# Install with npm install -g capcut-cli, then run capcut quickstart my-first --video clip.mp4 and open the result in CapCut.

CAVEATS

  • The README states clearly it is an independent project, not affiliated with ByteDance. Versions up to 0.17.0 had a local command-injection issue, and up to 0.17.2 could leak a device identifier — use 0.18.0 or later.
