WHY IT MATTERS

Most password managers keep the vault on the company’s servers. Monica puts local storage first and handles both worlds in one app — Bitwarden sync and KeePass (.kdbx) files — with your own WebDAV when you want the vault on more than one device.

BUILD FROM THIS

  • A Kotlin Android app holding logins, cards, identities, private notes and attachments in an encrypted vault, with TOTP codes generated in the same place. It uses its own MDBX vault format, designed around nested folders, attachments, commit history, conflict detection and snapshot recovery. Android 8.0 and later.

WHO IT'S FOR

People who would rather not park their vault on someone else’s server, and anyone already carrying a KeePass file.

START IN 5 MINUTES

# Install the APK from GitHub Releases, set a master password, and import your existing .kdbx if you have one.

CAVEATS

  • The interface and documentation are Chinese-first, with English and other translations alongside. The Windows build and the old browser extension are archived while a new extension is being written, and the repository notes that passkeys cannot be created on some Xiaomi HyperOS devices. It is maintained by one person.
