## TESIGN TAKE

It spends its effort on opening fast and not freezing rather than on features — a difference you feel immediately if you read logs for a living.

## WHY IT MATTERS

Past a few hundred megabytes, most editors stall on open. miu maps the file instead of loading it whole, so a large file opens straight away, and being written directly against C++ and Win32 keeps it light.

## BUILD FROM THIS

- Text and colour emoji are rendered with DirectWrite. It has regular-expression search and replace with case and whole-word options, multiple cursors, rectangular selection, unlimited undo, a dark mode and F1 help, and uses Google’s compact_enc_det to detect encodings. Built binaries are on GitHub Releases.

## WHO IT'S FOR

- People who open big logs and data files often, and Windows users after a lighter Notepad.
