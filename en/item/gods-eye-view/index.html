WHY IT MATTERS

Watching satellites or aircraft move normally means installing specialist software and wiring up a data source yourself. gods-eye-view moves that into a single browser screen, laying live open data over a photorealistic 3D globe. You install it with Pinokio or run it locally from the terminal and it opens in your own browser; it is built on Cesium. No license is declared in the repository, so check that before reusing the code.

BUILD FROM THIS

  • An internal briefing screen showing live open satellite data
  • A live observation demo page for a geography or space class

WHO IT'S FOR

Teacher
shows live flights, satellites and quakes in class
Data developer
wants to put open geodata on a 3D globe
OSINT beginner
views public signals in one place without paid tools

START IN 5 MINUTES

# Needs Node.js 24.14+ · then open http://localhost:4173
$ git clone https://github.com/bilawalsidhu/gods-eye-view.git
$ cd gods-eye-view
$ npm ci
$ npm run doctor
$ npm run dev

CAVEATS

  • Photorealistic 3D and voice control need Cesium ion, Google or OpenAI keys
  • Data may be delayed or modelled; the README rules out navigation or emergency use
  • GitHub metadata shows no license, but the README states MIT
