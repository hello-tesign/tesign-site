WHY IT MATTERS

Generating a PDF from a web app means choosing a renderer and laying out the document from scratch. pdfcn copies PDF components and blocks into your project through the same registry format and CLI flow as shadcn/ui, rendering through either Takumi or Forme. The code lands inside your project, so changing it is yours to do. Published under MIT, with every component previewed on the docs site, where the install command also lives rather than in the README.

BUILD FROM THIS

  • Order confirmations and invoices generated inside the app
  • A monthly report that moves dashboard numbers into tables and charts
  • An internal document template set sharing one brand theme

CAVEATS

  • No install command in the README; see the docs site
  • Depends on the Takumi or Forme renderer
