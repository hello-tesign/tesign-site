## TESIGN TAKE

It's an honest split: the one part with a real ongoing cost — brokerage sync — is the paid layer, while the core tracking stays free forever with no account.

## WHY IT MATTERS

Most portfolio trackers require handing account data to a cloud server. Wealthfolio is a desktop and mobile app that keeps everything on-device instead. Import trading activity across accounts and asset classes from CSV, and it computes time- and money-weighted returns, allocation and risk breakdowns, and dividend income over time. Automatic brokerage syncing (30+ institutions, read-only) and encrypted multi-device sync are an optional paid add-on called Wealthfolio Connect, but manual tracking and CSV import stay free forever.

## BUILD FROM THIS

- Pull scattered brokerage CSVs into one view of net worth and returns
- Track dividend and interest income over time to plan cash flow
- Build a custom page or feature with the TypeScript addon SDK

## WHO IT'S FOR

- Anyone with investments spread across several brokerages, wanting one net-worth view
- Someone who doesn't want investment data sitting in someone else's cloud
- A developer who wants to build a custom addon page

## START IN 5 MINUTES

```
# Install: download for macOS/Windows/Linux at https://wealthfolio.app/download (also an iOS app and self-hosted Docker)
# Build from source (needs Node, pnpm, Rust, Tauri):
$ git clone https://github.com/wealthfolio/wealthfolio.git
$ pnpm install
$ cp .env.example .env
```

## CAVEATS

- AGPL-3.0 · automatic brokerage sync and encrypted sync need the separate paid "Wealthfolio Connect" subscription
- macOS 12 needs current OS/Safari updates so its WKWebView meets the Safari 16 floor
