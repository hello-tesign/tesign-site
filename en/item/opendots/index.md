## TESIGN TAKE

It shows an ask, browse, approve, save flow inside one chat.

## WHY IT MATTERS

Using an AI agent usually means briefing a chat window every time. OpenDots is a starting point for Dots with their own role, permissions and computer, whose work lands as pages you can keep editing.

## BUILD FROM THIS

- Built with CopilotKit and AG-UI: Spaces for working documents, a live view of the agent's computer in chat, and human review cards, on web and mobile. You clone it and run it yourself.

## WHO IT'S FOR

- Developers who want to build their own agent workspace.
