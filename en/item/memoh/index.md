## TESIGN TAKE

Built for the case where you hand over a long job and walk away. For a question or two, you do not need it.

## WHY IT MATTERS

Handing work to an agent means it needs somewhere to keep files, open the web and accumulate results. Memoh gives each agent its own workspace — filesystem, desktop, browser, network and long-term memory — that stays up when your own machine is off.

## BUILD FROM THIS

- Go under AGPL-3.0. Run the built-in agent with your own API keys, or host the Claude Code and Codex agents you already use inside a Memoh workspace, and talk to them through Telegram, Discord or the web UI.

## WHO IT'S FOR

- People who leave research or repetitive work running with an agent, and teams juggling several at once.

## START IN 5 MINUTES

```
# Look at memoh.ai first, decide between self-hosting and signing up, then have your model API keys ready.
```

## CAVEATS

- You pay for model usage yourself, since it runs on your own API keys, and AGPL-3.0 means a modified service must publish its source.
