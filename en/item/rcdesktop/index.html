WHY IT MATTERS

Using WSL containers means typing commands. RC Desktop gives a Docker Desktop-style window, built in Rust with Slint so it starts fast and uses little memory without Electron.

BUILD FROM THIS

  • Start, stop, restart and remove containers, view logs and inspect output, and list images, volumes and networks. Deploy via a form, a pasted docker-compose file or a pasted docker run command, with compose stacks started and stopped together.

WHO IT'S FOR

Developers using WSL containers on Windows 11.

# Download the Windows build from the repository or project page.

CAVEATS

  • Windows only; the author says it is early and has rough edges. A brand-new project with 2 stars.
