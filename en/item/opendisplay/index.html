WHY IT MATTERS

Adding one more screen to a Mac usually starts with buying a device or paying for an app. opendisplay connects an iPhone or iPad you already own over USB or WiFi and uses it as a second monitor. It states low-latency H.264, Retina HiDPI and touch input. Written in Swift and published under GPL-3.0.

BUILD FROM THIS

  • A portable setup that adds a second screen in a meeting room
  • A desk layout with the iPad kept for tool panels only

WHO IT'S FOR

Mac user
adds a second screen in a meeting room or café
Solo business
wants a second monitor without a paid app
Developer

START IN 5 MINUTES

# Mac: open OpenDisplay.dmg from the latest release, drag to Applications (macOS 14+)
# iPhone/iPad: install the app via the TestFlight public beta (iOS 16+)
# Connect a data-capable USB cable, then allow Screen Recording and Accessibility

CAVEATS

  • Uses the private CGVirtualDisplay API, so a macOS update may break it
  • The iOS app installs via TestFlight or your own build, not the App Store
  • Encrypted WiFi transport is still on the roadmap
