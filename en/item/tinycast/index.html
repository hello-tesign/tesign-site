WHY IT MATTERS

The README leads with three numbers: zero third-party dependencies, zero telemetry, under 100 MB of RAM. It is SwiftUI and AppKit only, not Electron. It runs the Raycast extensions you already have, rendered as native SwiftUI, and imports shortcuts, clipboard history, snippets and quicklinks from a Raycast export (.rayconfig), so switching costs little. 34 window-management actions, clipboard history, currency and crypto conversion, and one-key meeting join all live in the same palette.

BUILD FROM THIS

  • Quicklinks, snippets and custom shell commands let you assemble a palette for your own work — internal URLs, deploy scripts or templates bound to a single global hotkey.

WHO IT'S FOR

Raycast users
bring extensions and settings into a native app
Memory-conscious Mac users
a palette under 100 MB instead of an Electron launcher
Keyboard-first workers
per-app hotkeys, 34 window actions, snippet expansion

START IN 5 MINUTES

# brew trust --tap abue-ammar/tinycast   # required for third-party taps
# brew tap abue-ammar/tinycast
# brew install --cask tinycast            # Apple silicon, macOS 26 or newer
# brew install --cask tinycast-universal  # Intel, macOS 26
# Then open Settings → General, record a global shortcut, and press it anywhere to summon the palette.

CAVEATS

  • Licence AGPL-3.0 (from the README badge and LICENSE file; not set in GitHub metadata). macOS 26 or newer, Apple silicon and Intel. The macOS 15 Sequoia cask is no longer maintained. The app is self-signed, so a DMG download needs one quarantine-clearing command. Pasting and snippet expansion need the Accessibility permission. Free; tipping via Polar is optional.
