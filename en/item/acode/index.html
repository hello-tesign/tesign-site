WHY IT MATTERS

When something needs fixing and you are not at a computer, the options are thin. Acode lets you edit HTML, CSS and JavaScript on an Android device and preview it in a browser immediately, and reaches server files through its built-in terminal and S/FTP and SSH connections.

BUILD FROM THIS

  • An Android app written in JavaScript: syntax support for many languages, a built-in JavaScript console, an Alpine-based terminal, S/FTP and SSH, community plugins and multi-language support. Available from Google Play, F-Droid and GitHub.

WHO IT'S FOR

People fixing a site on the move, students working from a tablet, and anyone who has to touch a server without a laptop.

CAVEATS

  • The source is MIT, but the official site also sells a Pro tier. Android only — and long code on a small screen is still long code on a small screen.
