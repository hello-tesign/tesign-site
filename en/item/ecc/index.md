## TESIGN TAKE

A large bundle of skills, memory and security rules, so pick a profile rather than switching everything on.

## WHY IT MATTERS

Agent configuration tends to accumulate as a few skills here and a few rules there. ecc gathers skills, instincts, memory, security and research-first development into one harness setup and applies it the same way across Claude Code, Codex, Opencode and Cursor. It is written in JavaScript, published under MIT, and has a separate documentation site.

## BUILD FROM THIS

- One shared baseline agent configuration for the team
- A personal rule set that moves intact when you change tools

## WHO IT'S FOR

- Team lead — gives the whole team one baseline agent setup
- Developer — wants the same rules across Claude Code and Codex

## START IN 5 MINUTES

```
# Needs Node.js 18+, Git and Claude Code 2.1+
$ npx ecc-universal@2.2.1 setup
# Or, in the Claude Code prompt:
# /plugin marketplace add https://github.com/affaan-m/ECC
# /plugin install ecc@ecc
# Do not stack two install methods in one harness
```

## CAVEATS

- Stacking two install methods in one harness duplicates skills and hooks
- Native Windows is supported with open defects in some optional features
- Hooks inject context each session (8,000 chars by default), raising token use
