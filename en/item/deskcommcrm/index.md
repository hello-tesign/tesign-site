## TESIGN TAKE

A CRM for businesses selling by chat; the installer covers domain, database and keys, but you run the server.

## WHY IT MATTERS

Where orders arrive by chat, conversation history and customer records end up split between a messenger and a spreadsheet. deskcommcrm keeps a CRM, native AI agents and WhatsApp in one self-hosted package. It is multi-tenant, MCP-ready, written in TypeScript and published under MIT. The homepage domain and its LGPD note place it in the Brazilian market.

## BUILD FROM THIS

- An internal CRM that takes chat orders and keeps the customer record
- Chat support automation that handles first contact and hands over

## WHO IT'S FOR

- Online seller — logs WhatsApp enquiries and orders in one place
- Small sales team — lets AI handle first contact and keeps the record
- Brazilian business — needs a self-hosted CRM built around LGPD

## START IN 5 MINUTES

```
# Prepare a Docker-capable VPS (4 GB RAM advised), a domain, a Supabase account and an LLM key
$ ssh -p PORTA root@SEU_IP
$ git clone https://github.com/melgarafael/DeskcommCRM.git
$ cd DeskcommCRM
$ bash hostgator-setup-kit/install.sh
# Then open https://<your-domain> and scan the WhatsApp QR code
```

## CAVEATS

- Docs and UI are Portuguese-first (English and Spanish READMEs exist)
- You supply the VPS, domain, Supabase project, LLM key and WhatsApp number
- The README leads with an affiliate link to one hosting provider (HostGator)
