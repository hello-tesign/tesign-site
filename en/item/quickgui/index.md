## TESIGN TAKE

The repo itself says not to use it for anything serious; for now it is something to watch, not build on.

## WHY IT MATTERS

Wrapping a desktop app in a webview is easy to build and heavy to run. quickgui is an experiment in the other direction: a GUI framework that renders on the GPU with no webview at all. It is written in Rust and has its own homepage. The repository calls itself experimental (the README states MIT OR Apache-2.0), so for now it is closer to something to look at than to build on.

## BUILD FROM THIS

- A desktop interface prototype running without a webview
- A performance comparison between rendering approaches

## WHO IT'S FOR

- Desktop developer — keeps an eye on GUI frameworks without a webview
- Go/Rust developer — wants a native window from the language they use

## START IN 5 MINUTES

```
# Needs Bun 1.4+ (Go 1.23+ for Go apps, a Rust toolchain for Rust, Xcode CLT on macOS)
$ bunx @quickgui/cli init my-app
```
