WHY IT MATTERS

Commercial game code is rarely visible, so indie developers seldom see how a finished game is built. Worlds Upon The Wind, a peaceful roguelite deckbuilder sold on Steam, releases its whole Godot project under CC0: GDScript source, PSD and SVG art, and the Steam build and publish scripts. The art is based on public-domain Japanese ukiyo-e prints and picture scrolls. Music and sound effects are excluded for licensing reasons, so a build from the repository runs silent.

BUILD FROM THIS

  • A structural reference for your own Godot 4 game
  • A card-game UI mock-up built on public-domain woodblock prints
  • A sample of scripts that automate multi-platform Steam releases

WHO IT'S FOR

Indie developer
building a first commercial-scale Godot project
Game art student
wants to see source PSDs and print-based art in use
Language-app maker
studying the vocabulary minigame structure

START IN 5 MINUTES

$ git clone https://github.com/max99x/wutw-public
# Install Godot 4.7, then Import wutw/project.godot from the Project Manager
# If console errors appear, wait for the import to finish and reopen
# Press F5 to run · music and SFX are excluded, so only cutscene voice plays

CAVEATS

  • Music and sound effects excluded; a repo build runs silent
  • A read-only mirror: pull requests are not merged
  • Dictionary and sentence data carry separate CC-BY-SA-style licenses
