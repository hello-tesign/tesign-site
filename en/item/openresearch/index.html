WHY IT MATTERS

Research handed to an agent runs one thread at a time, so a topic with several branches takes as long as the branches add up to. openresearch runs research agents in parallel and leaves the choice of model to you. It is written in Rust under the MIT license and has its own homepage. The repository description is one line, so supported models and usage have to be read from the docs.

BUILD FROM THIS

  • An internal research tool that splits competitor and market work into branches
  • A comparison run that pits one model's output against another's

WHO IT'S FOR

Researcher
runs several hypotheses in parallel with a record
ML engineer
tracks experiment variants in a git-based tree
Planner
splits competitor and market research into branches

START IN 5 MINUTES

# macOS/Linux CLI (Windows: install from Releases, beta):
$ curl -LsSf https://openresearch.sh/install.sh | sh
$ orx up
# The local dashboard opens at http://127.0.0.1:4791

CAVEATS

  • Requires Claude Code, Codex, OpenCode or Cursor to be installed
  • Official builds send usage analytics; orx telemetry off disables them
  • Windows support is beta and needs Git for Windows
