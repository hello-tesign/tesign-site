WHY IT MATTERS

Working on code through ChatGPT means pasting files in and copying results back out. Chat On Steroids pairs a desktop app with a Chrome extension so the chat can read and edit files in folders you approve, run tests and keep terminals open. Independent jobs can be split across workers, and Compact & Resume carries a session into a fresh chat. It uses your ChatGPT conversation rather than Codex quota, under MIT, though the builds are still an unsigned beta.

BUILD FROM THIS

  • A personal coding setup that fixes a local repo on a ChatGPT plan alone
  • A parallel workflow that splits independent jobs across workers
  • A hand-off routine that carries a long task into a new chat

WHO IT'S FOR

ChatGPT subscriber
wants local file work done without Codex
Solo developer
wants a long task split across several workers

START IN 5 MINUTES

# Download the Windows, macOS (Apple silicon) or Linux build from Releases
# Approve your project folder in Settings → Workspace
# Connect Core via Settings → Setup and add it in ChatGPT's Developer mode
# Open the extension folder and Load unpacked in Chrome; pairing is automatic
# Choose a model, write your task and send

CAVEATS

  • Windows build is unsigned and macOS unnotarized; verify checksums
  • Needs a ChatGPT account with Developer mode and custom MCP apps
  • Not affiliated with OpenAI, as the README states
