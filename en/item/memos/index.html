WHY IT MATTERS

An agent forgets once the window closes. MemOS is the layer that stores that memory and pulls it back when needed, handling knowledge bases, multi-modal material and tool memory through the same interface.

BUILD FROM THIS

  • Apache-2.0, exposing one unified API for store, retrieve and manage. Connected to DeepSeek Harness it adds automatic recall, background capture, hybrid retrieval and a local Memory Viewer.

WHO IT'S FOR

Developers building agents or support bots, and teams that need internal material remembered and queried.

START IN 5 MINUTES

# Read the getting-started guide at memos.openmem.net and follow the example that wires it into an agent you already run.

CAVEATS

  • A developer-facing component — not something you install and use as a finished app.
