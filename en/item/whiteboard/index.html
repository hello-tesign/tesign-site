WHY IT MATTERS

When an agent rewrites a lot of code, following how the pieces connect from text alone is hard. Whiteboard puts people and agents on one canvas to design the structure together: the agent draws the flow, and you can ask it in plain words to redraw it another way.

BUILD FROM THIS

  • A desktop app for macOS and Fedora. Connect a coding agent such as Claude Code or Codex from the welcome screen, and the agent uses an SDK to draw on the in-app canvas. The write-up, the flow diagram and the code it describes sit side by side.

WHO IT'S FOR

Developers and teams who design and review larger changes together with a coding agent.

START IN 5 MINUTES

# Download the app from install.dev.fast, open it, and connect Claude Code or Codex from the welcome screen.

CAVEATS

  • Per the README, downloads exist only for macOS and Fedora. It is only useful alongside a coding agent you already run.
