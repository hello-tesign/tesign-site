## TESIGN TAKE

Its focus is recording where each result came from, with versions and replay verification — while model costs stay separate and prompts plus attached context still go to whichever provider you pick.

## WHY IT MATTERS

It gathers research AI work that usually scatters across chat windows, notebooks, scripts and reporting tools into one desktop app. A five-step first run installs Claude Code, OpenCode, Codex or CodeBuddy as the agent runtime (no Node.js or admin password needed) and connects a model via a built-in cloud provider, a custom gateway or a Claude/Codex subscription login. It includes Python and R kernels, literature search across Europe PMC, OpenAlex and arXiv, 24 built-in data connectors and 22 featured skills, and every generated table or figure is kept as an immutable version with checksums, execution history and inputs that can be replayed in an isolated environment for verification. An Electron app for macOS, Windows and Linux; v0.29.0 (2026-09-13), Apache-2.0.

## BUILD FROM THIS

- The headless CLI and Node.js SDK share the desktop's local daemon, projects and permissions, so you could build an unattended pipeline that re-analyses a fixed dataset on a schedule and emits a report with verification records. Custom MCP connectors can bring in an in-house database.

## WHO IT'S FOR

- Computational researchers in bioinformatics, statistics, chemistry — agents run code, search literature, produce tables and figures
- Labs held to reproducibility standards — artifact versions, checksums and replay verification records
- Teams on Slurm clusters — notebook runs submitted over SSH
