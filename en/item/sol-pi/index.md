## TESIGN TAKE

Four efficiency mechanisms found by auto-research, packaged as a Pi extension; if you use Pi, try it.

## WHY IT MATTERS

Agent setups are still mostly tuned by hand, one prompt and one tool at a time. SoL-Pi addresses running that tuning as an automated research loop and is published under the NVlabs account. It is written in TypeScript under the MIT license and has its own project page. The work is research-shaped, so it reads more like a method to borrow than a product to install.

## BUILD FROM THIS

- An internal experiment loop that compares harness settings automatically
- A review note porting the method into your current setup

## WHO IT'S FOR

- Pi user — cuts tokens lost to repeated turns and re-read logs
- Agent researcher — studies the output of harness-efficiency experiments

## START IN 5 MINUTES

```
# Needs Node.js 22.19+ and npm
$ npm install --global @earendil-works/pi-coding-agent@0.84.2
$ pi install git:github.com/NVlabs/SoL-Pi
# Everything is off by default; enable it in ~/.pi/agent/sol-pi.json
```

## CAVEATS

- An extension for Pi 0.84.2 and not an official Pi distribution
- Everything is opt-in; without a config file nothing is enabled
- The reducer may send logs to a remote model; read SECURITY.md first
