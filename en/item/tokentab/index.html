WHY IT MATTERS

Run several agent CLIs side by side and each one has to be checked separately to see where the month's spend went. tokentab reads the session logs left by Claude Code, Codex and Gemini CLI and works the cost out by model, project and day. It is a Python CLI under the MIT license. The repository itself was created only recently.

BUILD FROM THIS

  • An internal monthly report of agent spend
  • A client settlement sheet with cost broken out per project
  • A scheduled job that pulls weekly usage

WHO IT'S FOR

Solo developer
wants to see where agent spend goes
Freelancer
attaches per-project AI cost to invoices
Team manager
reviews model usage share month by month

START IN 5 MINUTES

$ git clone https://github.com/crwdla/tokentab
$ cd tokentab
$ pip install .
$ python cli.py
# Web dashboard: python cli.py -web (localhost:4747)

CAVEATS

  • Prices come from a hand-kept table; an unmatched model shows as $0.00
  • Activity labels (coding, debugging, etc.) are stated to be a guess
  • Cursor support is still an unfinished stub
