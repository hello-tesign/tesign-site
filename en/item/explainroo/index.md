## TESIGN TAKE

You can start by giving your agent the repository address and a topic.

## WHY IT MATTERS

Recording a voice, editing and wrangling video tools just for a short explainer is a lot. With explainroo you tell your agent the topic, it writes the script and drawings, and you get an MP4.

## BUILD FROM THIS

- The agent writes two files, script.md and scenes.js; the open Kokoro voice model reads the script, Whisper times each word, and the drawings appear on cue. No account or API key. Example looks include paper, chalk and blueprint.

## WHO IT'S FOR

- Anyone who wants explainer videos without a studio, especially coding-agent users.

## START IN 5 MINUTES

```
# Paste the prompt from the README into your agent with your topic; it clones the repository and follows AGENTS.md.
```

## CAVEATS

- Needs a coding agent, and the README says it works best with Claude Code and Opus 5.5 for now. Recently released, with about 300 stars.
