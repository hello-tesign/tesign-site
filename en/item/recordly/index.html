WHY IT MATTERS

A product demo takes longer to edit than it does to record. recordly is built so that no editing skill is required: finish the recording and what comes out is already presentable. It is a desktop app for macOS, Windows and Linux, and the repository describes it as free. GitHub shows no license field, but the README states AGPL 3.0.

BUILD FROM THIS

  • Internal how-to clips recorded whenever a feature changes
  • A product demo clip for the landing page
  • A screen-recorded answer attached to a customer reply

WHO IT'S FOR

Product owner
re-records a demo clip whenever a feature changes
Support agent
attaches a screen recording to a reply
Solo developer
needs a short demo video for a landing page

START IN 5 MINUTES

# Download the macOS 14+, Windows 10 (19041+) or Linux build from Releases
# On Arch-based distros, install from the AUR:
$ yay -S recordly-bin
# Launch, pick a screen or window; stopping opens the editor

CAVEATS

  • GitHub metadata shows no license, but the README states AGPL 3.0
  • Linux cannot hide the cursor and system audio usually needs PipeWire
  • System-audio capture on macOS requires macOS 14 or newer
