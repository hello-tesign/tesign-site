WHY IT MATTERS

MonoCode is a Tauri desktop app that runs eight agents (Claude Code, Codex, Cursor CLI, Grok Build, OpenCode, Pi, omp, fx) as long as they are installed and logged in; each tab is a session and the README states that MonoCode does not sell tokens. Builds exist for macOS (.dmg for Apple Silicon and Intel), Linux (.deb, AppImage) and Windows (NSIS installer).

BUILD FROM THIS

  • With Node.js 20+ and a Rust toolchain you can run it from source with npm run tauri dev, trim it to the agents your team uses, or fork it to add an adapter for a new CLI agent.

WHO IT'S FOR

Developers juggling several coding agents
one window of tabs instead of many terminals
Team leads
compare and switch between the agents you already subscribe to
Tauri developers
reference for wrapping CLI agents in a GUI

START IN 5 MINUTES

# 1. Install and log in to at least one provider first: claude auth login / codex login / agent login
# 2. macOS (Apple Silicon): download MonoCode.dmg, open it, drag MonoCode to Applications
# 3. Linux: sudo apt install ./MonoCode_*.deb  or  chmod +x MonoCode_*.AppImage
# 4. Windows: download the NSIS installer from GitHub Releases and run it
# 5. From source: npm install, then npm run tauri dev

CAVEATS

  • MIT. Distributed for macOS (Apple Silicon and Intel), Linux x86_64 and Windows x86_64.
  • Each agent must be installed and logged in separately, and you pay each provider's subscription yourself.
  • The README says it is "very early and you should expect bugs".
