## TESIGN TAKE

Plenty of tools claim AI-assisted development; requiring a human gate five separate times, with a reviewable paper trail, is what's different here.

## WHY IT MATTERS

Hand a whole feature to an AI and scope creeps, or nothing gets verified. aSPARK splits the work across a Product Owner, Designer, Engineering Manager, Developer, Reviewer, QA Tester and Release Manager, and won't let a feature move to the next phase without your explicit gate approval.

## BUILD FROM THIS

- No service, no account — it installs into a project as Markdown. Running /spark drives the whole loop and leaves spec.md, plan.md, review.md, qa.md and a release log in .spark/; the QA phase opens a real browser and clicks through the running app.

## WHO IT'S FOR

- Solo developers and small teams building with Claude Code who want AI work checked at every phase, not just at the end.

## START IN 5 MINUTES

```
# Inside a Claude Code session, run /plugin marketplace add a-lottes/aSPARK then /plugin install aspark@aspark; on a new project, start with /charter.
```

## CAVEATS

- Requires Claude Code and Git; the browser QA phase (/demo-day) needs a browser integration such as Claude in Chrome or a Playwright MCP server. Newly released, with 24 stars so far.
