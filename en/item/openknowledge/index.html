WHY IT MATTERS

It opens any existing folder holding markdown or MDX files (codebases, wikis, Obsidian vaults) and edits them WYSIWYG, like a Google Doc or Notion page. Side-by-side AI editing with Claude, Codex, OpenCode, Pi and others is built in, and the app walks you through installing MCP and skills for the agent harnesses it detects. It ships as a desktop app for macOS, Windows and Linux, or as a web UI via `npm install -g @inkeep/open-knowledge` then `ok start --open`.

BUILD FROM THIS

  • Use the starter packs to build an LLM wiki or second brain, and let your own agents search and author documents through MCP. Team sharing and auto-sync run on git/GitHub underneath.

WHO IT'S FOR

Obsidian and markdown note-takers
edit an existing vault WYSIWYG
Claude Code and Codex users
write specs and docs side by side with an agent
Small teams
git/GitHub-based sharing and auto-sync

START IN 5 MINUTES

# npm install -g @inkeep/open-knowledge   # needs Node.js 24+ and git
# cd your-project
# ok init          # scaffold the project + wire up your AI editors (Claude Code, Claude Desktop, Cursor, Codex, OpenCode, OpenClaw)
# ok start --open  # serve the web editor and open it in your browser
# # Desktop app: DMG / Setup / deb-rpm from openknowledge.ai/download

CAVEATS

  • Licence GPL-3.0-or-later. The README states 'Private, local, and free'; homepage metadata lists it as free (price 0 USD), and no paid plan is shown as of 2026-09-15.
  • Desktop app: macOS Apple Silicon, Windows 10+ (x64/Arm64), Linux (x64/arm64). Intel Macs and servers use the CLI web app, which needs Node.js 24+ and git.
  • AI editing relies on harnesses you already run (Claude, Codex and so on), each with its own cost. Latest release v0.72.1 as of 2026-09-15. Built by Inkeep.
