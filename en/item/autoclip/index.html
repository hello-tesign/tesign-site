WHY IT MATTERS

Finding the watchable moments in a long interview, lecture or stream replay is tedious work. AutoClip reads the subtitles and audio with AI, scores highlights, writes titles, and cuts captioned short clips and compilations automatically.

BUILD FROM THIS

  • Available as a desktop app (Mac/Windows), a Docker web UI, or a CLI/MCP pipeline. Feed it a local file or a YouTube/Bilibili link, it prepares subtitles, scores highlight segments with your choice of model (Qwen, an OpenAI-compatible endpoint, Gemini, or a local Ollama/LM Studio model), and cuts clips. Direct publishing to TikTok, YouTube Shorts and more shipped in v1.3.2.

WHO IT'S FOR

Content creators who need short clips out of interviews, lectures or stream replays, and podcasters looking to cut editing time.

START IN 5 MINUTES

# Download the Mac or Windows build from GitHub Releases, add an API key for your chosen model in settings, and import a video.

CAVEATS

  • AI analysis needs an API key from a model provider such as Qwen or OpenAI (a local Ollama model is free). The interface defaults to Chinese, but has supported 8 languages including Korean since v1.3.1.
