WHY IT MATTERS

Tools that run Windows games on a Mac make you pick a Wine build yourself, and you only learn whether a game works after installing it. Highball sets up Wine, DXMT, D3DMetal and DXVK, connects a Steam or Epic library, and pulls per-game renderer verdicts and the anti-cheat blocklist from an open CC0 database before you download anything. App and CLI are GPL-3.0, the data is CC0, and the README rules out a paid tier. Apple Silicon and macOS 14 or newer only, and still in beta.

BUILD FROM THIS

  • A personal check of Mac compatibility before buying a game
  • A runtime for a Windows-only program on an office Mac
  • Your own lookup page built on the CC0 compatibility data
