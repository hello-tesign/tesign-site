WHY IT MATTERS

Every new hire loses days setting up a development environment. Coder defines that environment in Terraform and starts it on demand; idle workspaces shut down automatically to save cost, and access runs through a secure tunnel.

BUILD FROM THIS

  • Go under AGPL-3.0. Workspaces are defined in Terraform across EC2 VMs, Kubernetes pods or Docker containers, connected over a WireGuard tunnel. Coder Agents runs AI coding agents in the control plane on your own infrastructure, with no API keys inside workspaces.

WHO IT'S FOR

Teams with several developers, projects with rotating contractors, and organisations that cannot let code sit on personal laptops.

START IN 5 MINUTES

# Follow the quickstart at coder.com on a test server first, and gauge how much of your current setup has to move into Terraform.

CAVEATS

  • You run the servers yourself. Under AGPL-3.0 a modified service must publish its source, and some capabilities sit behind a paid Premium tier.
