## TESIGN TAKE

Twenty-eight Markdown files that impose a process instead of improvisation — discipline, not a new tool.

## WHY IT MATTERS

An agent improvises its process on every task, and the results swing with it. Viserys packages 28 skills mapped to DEFINE, PLAN, BUILD, VERIFY, REVIEW and SHIP, four reviewer personas and validation scripts as plain Markdown that drops into Claude Code, OpenCode, Cursor and similar tools. An OpenCode agent definition is included: open the folder, press Tab, pick viserys. No license is stated in the README, so check that before adopting it.

## BUILD FROM THIS

- A shared skill set so every agent on the team works the same stages
- A review step with code-reviewer and security-auditor personas
- An in-house skill template written in the same format

## WHO IT'S FOR

- Developer on agents — output quality swings from task to task
- Team lead — wants one written process for agent work
