## TESIGN TAKE

You brief it the way you would brief a motion designer.

## WHY IT MATTERS

Building video from a web page in a browser takes a long time to render. fframes has you write the video in Rust and SVG and render it on the GPU; the README says a 128-second video rendered in 36 seconds.

## BUILD FROM THIS

- Add the agent skill once and your agent installs it, creates a project, designs the motion, places the sound and checks the result. Because an agent cannot watch video, commands like inspect and strip turn it into PNGs and numbers it can read.

## WHO IT'S FOR

- Developers who want a coding agent to produce video.

## START IN 5 MINUTES

```
# Run npx skills add https://fframes.studio, then describe the video you want to your agent.
```

## CAVEATS

- Rust-based, and the README itself says the API is explicit and verbose. GPU requirements and supported operating systems are not stated in the README.
