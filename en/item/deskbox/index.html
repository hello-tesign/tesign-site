WHY IT MATTERS

It organizes desktop files with widgets backed by real folders, laid over the desktop without replacing Explorer or changing how files work. The README positions it as an open-source alternative to tools such as Stardock Fences and treats the todo, quick-note, search, weather and music widgets as extras. The current 1.5.1 x64 and ARM64 installers are .NET 10 Native AOT builds bundling Windows App Runtime 2.4, so they install offline.

BUILD FROM THIS

  • The C#, WinUI 3 and .NET 10 Native AOT code with a Rust native Shell layer is a reference for desktop-layer widgets and Native AOT packaging. External pull requests are not being merged, so treat it as something to read or fork rather than contribute to.

WHO IT'S FOR

Windows users with a cluttered desktop
folder-backed widgets, collapsible capsules
Paying Fences users
try a free GPL alternative
WinUI 3 developers
.NET 10 Native AOT plus a Rust Shell layer as reference

START IN 5 MINUTES

# 1. Download DeskBox_Setup_1.5.1_x64.exe (Intel/AMD) or DeskBox_Setup_1.5.1_arm64.exe (Snapdragon and other Windows on ARM) from GitHub Releases
# 2. Verify the hash with the matching .sha256 sidecar (installers are currently unsigned)
# 3. Run the installer — per-user by default, starts silently in the tray
# 4. Install Everything separately if you want file results in the search widget

CAVEATS

  • Licence GPL-3.0-only (earlier MIT releases stay MIT). Free, no account or cloud.
  • Windows 10 21H2 (build 19044) or later; Windows 11 22H2+ for the full visuals. Installers are unsigned, so verify the .sha256 hash. Weather and update checks use the network.
  • Solo developer, external PRs not accepted. File search needs Everything installed separately.
