## TESIGN TAKE

As in the README's demo, you can tell an agent 'cut clip every 16 bars'.

## WHY IT MATTERS

Cutting and arranging music or podcasts in a full DAW can be heavy and complex. Audionaut offers precise cutting, per-track playlists, multi-channel support and clean exports without that weight.

## BUILD FROM THIS

- A desktop app built in C++ on JUCE that runs on Windows, macOS and Linux. Connect an agent such as Claude over MCP and it edits the open project, with each edit as one undo step. It also analyses beats and segments.

## WHO IT'S FOR

- People who edit podcasts, music or recordings and want something light.

## START IN 5 MINUTES

```
# Get the app from audionaut.app; for agents, use the README's claude mcp add command (Node.js 18+).
```
