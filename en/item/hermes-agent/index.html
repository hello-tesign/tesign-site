WHY IT MATTERS

Every switch to another agent means rebuilding settings and context from scratch. hermes-agent is published under the Nous Research account around the idea of an agent that grows with the person using it. It is written in Python under the MIT license and has its own documentation site. The repository description is a single line, so the actual behaviour has to be read from the docs.

BUILD FROM THIS

  • An always-on personal agent for everyday work
  • An agent skeleton taken under MIT and reshaped for your own use

WHO IT'S FOR

Solo business
sends instructions from Telegram while a server works
Developer
keeps an always-on agent that builds its own skills
Automation owner
schedules daily reports and backups in plain language

START IN 5 MINUTES

# Linux, macOS, WSL2, Termux:
$ curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
# Windows (PowerShell):
$ iex (irm https://hermes-agent.nousresearch.com/install.ps1)
$ source ~/.bashrc
$ hermes

CAVEATS

  • Installs via curl | bash; read the script before running it
  • You connect a model provider yourself (API key or a Nous Portal subscription)
  • The README warns that antivirus on Windows may flag uv.exe as a false positive
