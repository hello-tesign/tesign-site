WHY IT MATTERS

Office alternatives are plenty, but 'open, save, formatting breaks' is the usual failure; GenOffice avoids it by rewriting only the blocks you edited and copying everything else byte-for-byte. An AI panel sits beside every document: edits arrive as tracked changes in Docs and as live formulas (SUMIF, for example) in Sheets, and each AI turn is a snapshot you can roll back. PDF to Word/Excel/PowerPoint conversion and OCR of scans (macOS and Windows) run on-device, and the model is either a Genspark sign-in or your own key for Claude, OpenAI, Gemini, DeepSeek and others, local servers included.

BUILD FROM THIS

  • With the bundled `genoffice` command line and agent skill, Claude Code, Codex, Cursor and others can create and check real .docx/.xlsx/.pptx files without opening a window — monthly reports, quotes, slide drafts. The HTML app proposes a design brief first, then builds a single-file landing page you can export to Word or PDF.

WHO IT'S FOR

Individuals and small teams handling .docx/.xlsx/.pptx without Microsoft Office
open, edit and save with the original formatting intact
People who want AI to do document work but review it
tracked changes, diffs, rollback, answers with cell citations
Developers automating documents with coding agents
create, convert and check files headless via the `genoffice` CLI and skill

START IN 5 MINUTES

# 1. Download from https://github.com/genspark-ai/genoffice/releases/latest — macOS 11+ (.dmg, arm64/x64), Windows 10+ x64 · Windows 11 on Arm ARM64 (.exe), Linux glibc 2.34+ (.deb/.rpm/.AppImage)
# 2. Linux (Debian/Ubuntu): sudo apt install ./genoffice_<version>_amd64.deb
# 3. Check the CLI: genoffice --version
# 4. Skill for coding agents: npx skills add genspark-ai/genoffice

CAVEATS

  • Apache-2.0 licence (the ee/ directory is under a separate enterprise licence; the GenOffice and Genspark names and logos are Mainfunc trademarks, not covered). The apps are free with no paid tier, but AI features need a network connection and either a Genspark sign-in (the homepage says Genspark credits) or your own API key; model costs are yours.
  • macOS 11+, Windows 10+ x64 · Windows 11 on Arm ARM64, Linux x86_64 with glibc 2.34+; macOS and Windows installers are signed.
  • Official packaged builds send limited usage analytics by default (never document content, file names or paths); disable under Settings → General. 'In active development' per the README.
