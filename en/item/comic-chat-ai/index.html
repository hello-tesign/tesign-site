WHY IT MATTERS

1990s Microsoft Comic Chat was an unusual program that staged a chat as an automatic comic strip, and it was discontinued long ago. Comic Chat for AI revives that same panel, balloon, avatar and emotion renderer, this time drawing an automatic comic from a conversation with ChatGPT instead of another person.

BUILD FROM THIS

  • A 32-bit MFC app for Windows
  • Unlike the original, IRC, the legacy server dialogs and member lists are removed; a locally installed Codex handles the browser sign-in and connects to ChatGPT, and the app states it does not store the credentials. The source is MIT-licensed, and the repository is independent of the original Microsoft project.

WHO IT'S FOR

Anyone who remembers the original Comic Chat, and people who want a different record of a ChatGPT conversation.

START IN 5 MINUTES

# Download the Windows build from GitHub Releases and extract it intact so CChat.exe stays next to the comicart folder.

CAVEATS

  • It is still alpha, a 32-bit app on 64-bit Windows 11, and needs Codex installed locally plus a ChatGPT sign-in to work. The repository states it is not affiliated with Microsoft or OpenAI.
