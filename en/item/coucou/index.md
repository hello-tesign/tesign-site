## TESIGN TAKE

On Windows and Linux, where there is no notch, it appears along the top edge of the screen.

## WHY IT MATTERS

It is easy to miss a permission prompt while your AI agent works in another window. Coucou shows what each session reads, edits and runs, and puts Allow and Deny buttons up top when Claude Code asks.

## BUILD FROM THIS

- Live view of Claude Code, Gemini CLI, Antigravity and other agent sessions, a jump to the right terminal window (macOS), and chat with Claude from the notch. It says there is no telemetry or account and that keys live in the OS keychain.

## WHO IT'S FOR

- Developers who run several AI coding agents at once.
