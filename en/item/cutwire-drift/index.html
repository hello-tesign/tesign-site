WHY IT MATTERS

Built on Qt 6 and FFmpeg, it puts a multi-track timeline (trim, split, snap, ripple), GPU effects and transitions, auto captions you can edit line by line, click-to-cut-out subjects, masks, green screen and multicam in one window. A built-in local MCP server (off by default) lets Cursor or Claude Code place clips and export from the open project. It ships on Flathub, Windows, macOS (Apple Silicon) and as Android APKs; the latest release is v0.6.0 (2026-09-13).

BUILD FROM THIS

  • Because the MCP server lets an agent import media, place clips and export, you could wire up a semi-automatic pipeline that cuts one long recording into several Shorts. GPL-3.0 means derivatives must publish their source.

WHO IT'S FOR

Creators cutting Shorts and Reels
generate captions, then fix each line
Game-clip and school-project editors
MP4 and GIF export without a watermark
Developers automating edits with an AI agent
local MCP server, off until enabled

START IN 5 MINUTES

# flatpak install flathub org.cutwire.Drift
# flatpak run org.cutwire.Drift
# # Windows (.exe / portable zip), macOS (.dmg, Apple Silicon) and Android (APK) builds are on the latest GitHub release
# adb install Drift-*-arm64-v8a.apk   # on a phone

CAVEATS

  • GPL-3.0 — modified or redistributed builds must publish source
  • macOS build is Apple Silicon only; Android is a sideloaded APK, not on the Play Store
  • Latest release v0.6.0 (2026-09-13), still 0.x; fonts, stickers, extra effects and speech models download separately inside the Addon Manager
