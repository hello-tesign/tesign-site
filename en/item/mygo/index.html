WHY IT MATTERS

Desktop apps often carry a whole bundled web runtime. MyGo uses the webview already on the OS or draws a native UI on the GPU, aiming for small apps with low memory and CPU use.

BUILD FROM THIS

  • Pure Go with no cgo, so you can build for every platform from any machine. Web pages call Go through a TypeScript client generated from your Go code, and there is a native toolkit with layout, widgets and screen-reader support. Windows, menus, tray, notifications, installers, signing and auto-updates are included.

WHO IT'S FOR

Go developers who want to ship small desktop apps.

START IN 5 MINUTES

# Create a project with bunx mygo-cli init my-app, as the website shows.

CAVEATS

  • An early project at version 0.2.6 with about 320 stars; macOS, Linux and Windows are listed.
