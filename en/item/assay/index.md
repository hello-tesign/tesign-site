## TESIGN TAKE

Because it needs no AI and gives repeatable results, it suits re-running after every fix.

## WHY IT MATTERS

Writing tests is a chore, so many changes ship unchecked. assay finds every control on the page, uses all of them, and reports what went wrong.

## BUILD FROM THIS

- It opens the page in Chromium and builds its checks from the controls it finds. If pressing a tag filter twice leaves the list filtered, it reports that with before and after views. No test code, no LLM, no API key, and every run gives the same result. A skill for coding agents is included.

## WHO IT'S FOR

- Developers who want to check their own web pages before shipping.
