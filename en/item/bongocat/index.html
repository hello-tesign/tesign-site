WHY IT MATTERS

Desktop pets tend to sit on a heavy runtime or exist for one OS only. BongoCat is rewritten as a native app in C, SDL3 and OpenGL: it reads keyboard, mouse and gamepad input locally to drive a Live2D model, and runs on Windows, macOS and Linux. The README states that it records and uploads no input and carries no ads or analytics, and downloads are on the Microsoft Store and GitHub Releases. Source is AGPL-3.0; the default model assets are MIT.

BUILD FROM THIS

  • A reactive mascot in the corner of a stream layout
  • A branded desktop pet running your own character model
  • A C study piece on SDL3 and OpenGL input handling

START IN 5 MINUTES

# Download the latest build from the Microsoft Store or GitHub Releases
# Building from source needs CMake 3.24+, C11/C++17 compilers and OpenGL dev files
# Live2D rendering requires the Cubism SDK for Native, added separately

CAVEATS

  • Source is AGPL-3.0; check the terms for how you distribute
  • Built without the Cubism SDK, you get only a diagnostic backend
  • The first configure step downloads dependencies and needs network
