## TESIGN TAKE

Self-hosted AI chat tools aren't rare, but being able to try the whole thing from a single Colab link, with no Docker required, lowers the barrier a lot.

## WHY IT MATTERS

ChatGPT-style services are convenient, but the bill and the chat history both live on someone else's server. ENZO is a chat-and-agent workspace where you paste in your own API keys — OpenRouter, Google AI Studio, NVIDIA NIM and more — and every request goes straight from your browser to the provider you picked, with no account or subscription taking a cut in between.

## BUILD FROM THIS

- One Docker command installs the whole thing (docker compose up -d), or try it with no install at all via a Google Colab notebook that boots in about five minutes. It ships a 300+ model catalog, agents that draft their own operating manual from a plain-English task, and 74 bundled skills; keys are encrypted and saved in the browser.

## WHO IT'S FOR

- Anyone who wants to compare multiple AI models without racking up subscriptions, and keep their chat history in their own hands.

## START IN 5 MINUTES

```
# The easiest path is the README's "Open in Colab" button — run all cells. To self-host, clone the repo and run docker compose up -d, then open localhost:5001.
```

## CAVEATS

- You need your own API key from at least one provider (OpenRouter and Google AI Studio both offer free tiers). Running it on Colab caps a free session at roughly 12 hours.
