## TESIGN TAKE

The point is bringing the muscle memory of a desktop file manager straight into the terminal.

## WHY IT MATTERS

A terminal file manager is usually keyboard-only, and that takes time to learn. tfm keeps clicking, dragging and right-click menus, with two panes side by side so F5 copies and F6 moves between them. Network locations — sftp, smb, WebDAV, FTP — connect from the sidebar too.

## BUILD FROM THIS

- Built with Bun; in a terminal that supports the kitty graphics protocol (kitty, ghostty, WezTerm, Konsole and others) it shows real image and video thumbnails, falling back to Nerd Font glyphs elsewhere. It has an embedded terminal, archive extract/compress, and more than 30 themes.

## WHO IT'S FOR

- People who live in the terminal but do not want to give up the mouse, and Linux desktop users.

## START IN 5 MINUTES

```
# Install with curl -fsSL https://raw.githubusercontent.com/clarkarch/tfm-tui/main/install.sh | bash.
```

## CAVEATS

- It is still beta, and the repository says plainly to back up anything irreplaceable before a file operation. Linux only, and image thumbnails plus cross-app drag work only in kitty-family terminals.
