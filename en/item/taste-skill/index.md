## TESIGN TAKE

A rule set that changes the agent's default look; whether the result matches your taste is yours to judge.

## WHY IT MATTERS

Leave the interface to an agent and the same familiar default layout keeps coming back. Taste-Skill changes those defaults, adding judgement about what not to produce. It attaches to tools such as Claude Code and Codex and is published under MIT. What counts as a good result is a matter of taste, so whether it matches your team's standard is something to see for yourself.

## BUILD FROM THIS

- A team setting that changes the default look of front-end output
- A design exploration step that produces several options quickly

## WHO IT'S FOR

- Founder — produces several landing-page options quickly
- Frontend developer — wants agent output to look less generic
- Designer — needs image-generation guidance for reference boards
