Deskreen CE (Community Edition) (Over 2M downloads during 5 years since launch) Deskreen turns any device with a web browser into a secondary screen for your computer To learn more visit our website: deskreen.com Donate to support Deskreen Open-Source Deskreen is an electron.js based application that uses WebRTC to make a live stream of your computer screen to a web browser on any device. It is available for MacOS, Windows and Linux operating systems. The current open-source Community Edition version has limited features.
