FAQ

How do you choose?

A human judges whether it is a real, usable product, whether anything about it is new, and whether seeing it makes you want to try it. AI only thins the candidates; the last call is human. One exception: the first lists (13–14 September 2026) were chosen by AI and are being re-reviewed.

How many per day?

Ten a day, as a rule. The list is finite: reach the end and you get "You're done for today." Nothing more arrives that day.

Can money change the ranking?

No. There is no paid placement. The list and its order are exactly what a person chose, with one stated exception: the first lists of 13–14 September 2026.

Where does the data come from?

Public sources collected daily: GitHub activity (GH Archive), Hugging Face Spaces, Show HN. We never download and run someone else's code.

Can I submit my product?

Yes. Send a link and one line of description to hello@tesign.com and it goes into the pool. Selection is not guaranteed, and submitting never changes the order.

Where do saved items live?

Only inside the browser you are using. There is no account and no server copy, so saves do not follow you to another device and clearing browser data clears them.

TESIGN / RADAR

Collect broadly. Reject aggressively. Publish sparingly.

TESIGN Radar collects newly released SaaS, AI apps, developer tools and design experiments from public sources every day, rejects most of them, and publishes only the few worth trying, installing, sharing or building from.
