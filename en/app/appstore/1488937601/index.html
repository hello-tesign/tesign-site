STORE DESCRIPTION

Magic Packet은 로컬 네트워크와 인터넷을 통해 컴퓨터를 원격으로 관리하는 앱입니다. iPhone, Apple Watch, 위젯, Siri로 컴퓨터를 깨우고, 종료하고, 재시작하고, 모니터링하세요.

사용 사례:

- 영화를 보기 전에 홈 NAS 깨우기

- RDP, VNC 또는 TeamViewer로 홈 PC에 연결

- 다운로드, 스트리밍 또는 렌더링 중 컴퓨터가 절전 모드로 들어가지 않도록 하기

- 멈춘 PC를 원격으로 재부팅

- 인터넷을 통해 컴퓨터 종료 및 재시작

WAKE ON LAN:

- 즉시 magic packet 전송

- 로컬 네트워크와 인터넷에서 작동

- 각 호스트별 사용자 지정 UDP 포트

- SecureON 지원

- broadcast, IP 주소 및 도메인 이름 지원

원격 관리:

- 종료, 재시작, 절전, 최대 절전 및 잠금

- Windows, macOS, Linux용 Magic Packet Server를 통해 작동

- 로컬 네트워크에서 서버 자동 검색

상태 및 모니터링:

- ping 또는 HTTP를 통한 가용성 확인

- 자동 새로 고침이 있는 온라인 / 오프라인 상태

- 노트북 배터리 수준 모니터링

- 호스트 상태 빠른 확인…
