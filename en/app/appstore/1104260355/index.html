STORE DESCRIPTION

동영상 손떨림 즉시 보정

Deshake는 iPhone, iPad, iPod touch에서 데스크톱 수준의 손떨림 보정 기능을 제공함으로써 마음에 드는 순간이 담긴 동영상에서 모든 손떨림을 개선합니다. 사진 보관함에서 동영상을 선택하고 설정을 조정하기만 하세요. 휴대폰에서 결과를 실시간으로 미리 확인할 수 있습니다! 사용자의 것과 같은 실제 동영상들에서 테스트되고 대부분의 전문적인 앱보다 성능이 우수한 차세대 손떨림 보정 알고리듬을 채택해서 속도가 굉장히 빠릅니다.

우수한 손떨림 보정 기술

- 실시간 미리 보기를 통해 손떨림 보정 정도 조정

- 흔들림 및 왜곡 즉시 제거

- 수평, 수직, 회전 모션에 대한 보정

- 초고속 GPU 가속 비디오 처리 가능

- 수초 내에 전문가 수준의 동영상 제작

다양한 기능

- iOS 사진 보관함의 어떤 동영상에도 즉시 적용

- 호환 가능한 다른 iOS 앱에서 동영상 가져오기

- 저장 전 실시간으로 손떨림 보정 결과 미리 보기

- 동영상을 엉망으로 만드는 워터마크 또는 다른 상술 없음

- 광고 없음
