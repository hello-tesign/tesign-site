STORE DESCRIPTION

Banner (배너)는 사용자가 원하는 메세지를 표시하는 LED 매트릭스 형식의 디스플레이며, 다음과 같은 항목을 표시할 수 있습니다.

- 5개의 메세지

- 35가지의 심볼, 그림 문자

- 날짜 (3가지 형식)

- 시각 (3가지 형식)

- Bluesky (3종류의 표시할 게시물 수 설정, 사용자 아이디 또는 키워드 검색 지정)

- iPod에서 재생 중인 곡 정보 (아티스트명, 곡명, 앨범명)

Banner (배너)는 이하와 같은 다양한 설정이 가능합니다.

- 스크롤 속도

- 깜빡임 속도

- 랜드스케이프 모드

- 상하반전 표시 모드

- 미러 모드

- 화면 더블 탭으로 설정 메뉴 표시

- 잠자기 기능 끄기

- LED의 크기 (3종류)

- 글자의 크기 (3종류)

- LED의 모양 (6종류)

- LED의 색 (색상, 채도)

- LED 색의 랜덤화

참고

- Bluesky 게시물은 1분마다 또는 모든 게시물이 표시된 후 업데이트됩니다.

- Banner Basic는 광고가 있는 무료 버전이며, Banner와 Banner Extreme은 광고가 없는 유료 버전입니다.

- Banner Extreme은 스타일과 속도 면에서 다른 버전과 약간 다릅니다.
