STORE DESCRIPTION

추적과 광고를 줄여 더 편하게 인터넷을 이용해요. 오리집은 Safari 차단, DNS 보호, 선택형 DPI 보호를 한곳에서 관리할 수 있는 앱이에요.

■ Safari 광고 차단

오리집이 직접 확인해 만든 목록으로 광고와 추적 요소, 광고가 사라진 빈자리를 줄여요. 사이트가 제대로 보이지 않으면 그 사이트만 허용하고, 거슬리는 요소는 직접 골라 가릴 수 있어요. 지원되는 쿠키 안내창에서는 거절을 돕고, 원하면 차단 목록도 직접 추가할 수 있어요.

■ DNS 보호

‘오리집’ 방식은 기기 안의 목록으로 광고·추적·피싱 주소를 걸러요. iPhone·iPad에서는 로컬 VPN, Mac에서는 DNS 프록시를 사용해요. 허용된 DNS 질의는 선택한 DNS 서버로 전달돼요. 기본값과 IP 주소로 추가한 DNS는 오리집이 암호화하지 않으며, HTTPS DNS를 고르면 해당 서버까지의 전송을 암호화해요.

DPI가 꺼진 동안에는 최근 DNS 기록을 기기 안에서 확인하고, 주소를 허용하거나 막을 수 있어요. ‘기본 OS’ 방식은 직접 입력한 DNS 공급자를 시스템 DNS로 사용하는 기능이며, 오리집의 로컬 차단 목록과 기록은 적용하지 않아요.
