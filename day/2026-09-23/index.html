오늘 볼 만한 6가지

오늘은 원래 있던 도구를 자기 손 안에 그대로 가져오는 물건이 많았습니다. 국제앰네스티가 페가수스 스파이웨어 조사에 썼던 포렌식 도구를 내 폰에 직접 돌려 보고, 캡컷·젠잉 편집 파일을 업로드 없이 터미널에서 고치고, 300여 개 AI 모델을 내 API 키로만 쓰는 채팅 작업공간을 도커나 코랩 한 번으로 띄웁니다. 나머지는 저가 마우스를 트랙패드처럼 쓰게 하는 맥 유틸리티, 긴 영상에서 AI가 하이라이트만 잘라 주는 앱, Claude Code로 기능을 만들 때마다 사람 승인 관문을 다섯 번 두는 에이전트 팀입니다. 오늘은 후보 상당수가 같은 브랜드를 홍보하는 게시물이라 걸러낸 것이 많아 여섯 개만 골랐습니다. 라이선스와 제약은 항목마다 그대로 적었습니다.
