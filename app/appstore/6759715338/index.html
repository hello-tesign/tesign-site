스토어 설명

Scrolly는 Safari 자동 스크롤 확장 프로그램입니다.

웹툰을 볼때, 요리하면서 레시피를 볼 때, 운동 중에 가이드를 읽을 때,

악보를 볼때 등, 손을 쓰기 어려운 상황에서도 모든 웹페이지를

자동으로 스크롤해 드립니다.

+ 주요 기능 +

* 원터치 시작/정지

- Safari 팝업에서 버튼 하나로 자동 스크롤을 켜고 끕니다.

* 속도 조절 (1x ~ 20x)

- 느린 정독부터 빠른 훑어보기까지, 슬라이더로 자유롭게 조절.

* 방향 선택

- 위 ↑ / 아래 ↓ 어느 방향이든 원하는 대로.

* 루프 모드

- 페이지 끝에 도달하면 자동으로 처음으로 돌아갑니다.

- 대본, 긴 문서 반복 열람에 최적.

* 자동 일시정지

- 화면 터치시 즉시 멈추고, 3초 후 자동 재개.

- 스크롤 중에도 자유롭게 확대·링크 클릭 가능.

* 타이머 (5분 ~ 60분)

- 원하는 시간이 지나면 자동으로 스크롤을 종료합니다.

- 취침 전 독서나 시간 제한 열람에 유용.

* 제스처 단축키

- 더블탭: 일시정지 / 재개 즉시 전환

- 트리플탭: 속도를 기본값(2x)으로 초기화

* 플로팅 위젯

- 페이지 위에 떠 있는 미니 컨트롤…
