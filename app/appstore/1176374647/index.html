HealthFace는 건강 앱의 데이터를 컴플리케이션과 위젯으로 바꿔 주어, 중요한 수치를 언제든 한눈에 확인할 수 있습니다. 걸음 수, 체중, 혈당, 혈압, 물, 카페인, 수면 등 100가지가 넘는 데이터 유형을 지원합니다.

■ 시계 페이스에서

* 컴플리케이션으로 모든 건강 데이터를 Apple Watch 시계 페이스에 표시

* 하나의 시계 페이스에 여러 데이터 유형 표시

* 목표 달성 진행 상황 표시(예: 10,000걸음)

* 컴플리케이션을 탭해 손목에서 바로 새로운 값 기록

* Apple Watch에 저장하기 전에 iPhone에서 컴플리케이션을 실시간으로 미리 보기

■ iPhone과 iPad에서

* 홈 화면과 잠금 화면용 위젯

* iPhone, iPad 또는 Apple Watch 앱에서 몇 번의 탭으로 데이터 기록

* 자주 기록하는 데이터 유형을 선택해 언제나 빠르게 입력

* 체중으로 하루 단백질 목표를 계산하는 등, 여러 단위를 조합한 맞춤 계산식 생성

* 수백 가지 고품질 아이콘 중에서 선택
