스토어 설명

CamScanner는 문서 스캔, 저장, 관리, 공유, 그리고 동기화 기능을 지원해서 핸드폰을 휴대용 스캐너, 팩스, PDF변환기, 텍스트 변환기를 만들고 문서 공유 플랫폼을 제공합니다.

----유료버전 전용 기능----

* 무료버전의 모든 기능 사용 가능

* 신글 페이지안에 적힌 글자를 인식 및 내보내기 가능

* 400M의 클라우드 저장 공간이 사용 가능（무료버전은200M만 사용 가능)

* 내보내는 PDF파일이“Scanned by CamScanner”의 워터마크가 없음

* 애플리케이션안에 광고가 없음

----전세계최고 핵심 기술----

*문서를 자동으로 스캔하며 고화질 PDF, JPRG문서로 생성합니다.

*사진에 적힌 글자를 자동으로 인식해서 키워드를 입력하면 문서를 찾아냅니다.(회원 전용)

*사진에 적힌 글자를 편집하거나 텍스트로 내보냅니다.(공급계정 전용)

*문서를 공유하면서 친구를 초대하여 같이 보거나 리뷰를 작성합니다.

----주요 기능----

[핸드폰용 스캐너]
