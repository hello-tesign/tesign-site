스토어 설명

Seconds Pro is an interval timer for HIIT, Tabata, EMOM, circuits and any workout built from timed intervals. It calls each interval out loud, keeps running with the screen off, and runs on iPhone, iPad and Apple Watch.

Apple has featured it, and Joe Wicks, The Body Coach, has said it is the fitness app he uses more than any other.

BUILD ANY WORKOUT

- Start from a HIIT, Tabata or circuit template, or build a timer from scratch with sets, rounds and intervals of different lengths.

- Chain timers into one compound timer, so a warm-up flows into the main set and then a cool-down.
