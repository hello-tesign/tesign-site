TESIGN Radar 소개

TESIGN Radar는 AI가 고른 오늘의 도구와 숫자로 보는 급상승·역대 순위를 소개합니다. 운영자의 위임으로 선정하며, 별·증가량·교차 출처·업데이트·라이선스를 근거로 보여줍니다. 목록은 운영자의 위임을 받아 AI가 고릅니다. 2026년 9월에는 사람이 직접 검수하지 않습니다. 별 총합·증가량·교차 출처·마지막 업데이트·라이선스를 판단 근거로 보여줍니다. 1인 사업자 tesign이 운영합니다. 광고·유료 배치·계정·결제는 없습니다.

오늘의 목록은 열 개를 기준으로 고릅니다. 급상승은 최대 100개, 역대는 최대 250개로 끝이 있는 목록을 만듭니다.

목록은 운영자의 위임을 받아 AI가 고릅니다. 2026년 9월에는 사람이 직접 검수하지 않습니다. 별 총합·증가량·교차 출처·마지막 업데이트·라이선스를 판단 근거로 보여줍니다.

처음 본 시각은 실제 시스템 기록입니다. 과거 기록은 라이브 발견으로 표시하지 않습니다. 이력이 없는 날은 빈 막대로 표시하며, 숫자는 직접 사용해 본 평가가 아닙니다.

순위는 이렇게 계산합니다

급상승은 해당 기간 별 증가가 200 이상이거나, 별 총합이 100 이상이면서 증가가 총합의 20% 이상인 저장소를 증가량순으로 보여줍니다. 생성 30일 이내는 NEW입니다. 24시간 증가가 총합의 30% 이상이고 GitHub 밖의 신호가 없으면 급등 주의를 표시합니다.

역대 순위 = 별 총합 × 생존계수 × 교차계수. 마지막 push가 기준 시각에서 90일 이내면 생존계수 1.0, 365일 이내면 0.8입니다. 교차계수는 1 + 0.1 × (서로 다른 출처 수 − 1), 최대 1.5입니다. 별 1,000 이상이며 라이브러리 카테고리가 아닌 저장소만 포함합니다. 화면에는 원래 숫자와 순위만 표시합니다.

두 순위 모두 AI 분류에서 “바로 쓸 수 있는 제품”으로 통과한 저장소만 넣습니다. 보관된 저장소·포크·필터됨·폐기·병합 항목, 크랙·활성화·채굴처럼 별을 조작하는 이름 패턴, README 없는 저장소, 링크·튜토리얼 모음(awesome 류), 라이브러리·프레임워크·SDK·런타임은 이름·주제·설명 기준으로 제외합니다. 기준 시각은 저장된 GitHub 이력의 마지막 시간입니다. 별 증가는 수집된 관측치이며 모든 별 이벤트를 보장하지 않습니다.
