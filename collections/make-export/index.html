  1. Recordly

    녹화만 하면 편집 없이 내보낼 만한 데모 영상을 만듭니다.

  2. OpenMontage

    코딩 도구에 붙여 영상 제작 공정을 통째로 돌립니다.

    곡을 만들고, 기존 곡을 다시 부르게 하고, 부분만 고칩니다.

    AI · GitHub · Apache-2.0 · 2026.09.13

  4. Amagine3D

    제품 설명과 치수에서 3D 프린터로 뽑을 수 있는 하드웨어 외장 설계를 만듭니다.

    하드웨어 · GitHub · Apache-2.0 · 2026.09.14

  5. pdfcn

    복사해 붙이는 React 컴포넌트로 표·청구서·보고서 PDF를 만듭니다.

    개발 도구 · GitHub · MIT · 2026.09.14

  6. PDF Pocket Tools

    HTML 파일 하나가 PDF 합치기·나누기·회전·재배열을 오프라인으로 처리합니다.

    디자인 · GitHub · MIT · 2026.09.14

    구조도와 흐름도를 의존성 없는 HTML 한 파일로 뽑아냅니다.
