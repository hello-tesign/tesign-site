Peach 给自己用的私人影片馆藏：本地硬盘、网盘和关注的创作者，放在一个地方看。 官网 · 下载安装包 · 在线演示 · 介绍视频 · 问题反馈 · 需求看板 · 路线图 · 文档 · English https://github.com/user-attachments/assets/a5610874-e611-41bb-be22-7d99f0d64b62 18+ 仅供成年人管理自己的成人内容馆藏。仓库不含媒体或站点数据；连接外部站点需有相应账号和访问权。 能做什么 - 本地、网盘一起看 ：硬盘与已挂载的 115、PikPak、OneDrive 等网盘汇成一个馆藏。 - 播放墙挑片 ：拖动全屏封面墙，点开原位播放；同一番号的不同版本与分卷集中切换。 - 播放器字幕 ：加载本地字幕，按番号搜索 SubtitleCat 简繁中文字幕并选择加载，调整字体、字号、颜色与背景。在线搜索无需 API Key，来源可能包含机翻。 - 接手已有收藏 ：直接读取 NFO 和海报，缺少的标题、女优、厂牌与封面可从多个来源补齐，保留手动修改。 - 跨站关注 ：同一创作者在 FANBOX、Patreon、Kemono 等站点的更新汇到一起，同一作品合成一张卡。 - 追新作、找想看的 ：按女优订阅新作，按口味发现作品，用「想要」清单留住待找的片子。 - 云下载 ：按番号查找资源或粘贴磁力，提交到 115 或 PikPak，落地后自动整理入库。 - 浏览器添加 JAV ：在 JavDB、MissAV、Jable 等站点识别或选中番号，一键交给 Peach 云下载入库。用户脚本独立维护，见安装与配对。 - 口味 ：结合观看、反馈、馆藏、浏览历史、书签与关注关系分析偏好。一次读取本机浏览器的历史和书签，也可导入 HTML 书签或 Chromium Bookmarks JSON；来源可停止读取或删除。见口味数据来源。 观看记录、收藏和设置保存在本机。扫描不动原文件；手动整理先预览，可撤回上一批。 扫描、关注更新和新作资料采集会保存进度，应用重启后继续处理未完成的项目。恢复范围见断点续跑。 「发送版本统计与错误诊断（推荐）」默认勾选，可在安装、首次设置或设置页取消。两类技术事件由同一开关控制，已保存的关闭选择会保留。启用后向 Sentry 发送页面列出的技术字段，不自动上传完整日志、诊断 ZIP、媒体信息或观看记录。见远程诊断说明。 馆藏与口味明细上传在安装器和设置页另设独立选项，默认关闭。设置页先展示完整字段与本机预览，经明确同意后，每周上传作品、标签、评分、观看汇总及全部偏好维度的明细；不含账号、设备或安装标识。明细仍有跨次关联与再识别风险，接收服务可见连接 IP。见馆藏与口味群体研究。 截图 在线演示 可直接体验搜索、筛选和资料页，操作不会保存。点击截图查看原图。 馆藏：按人物、来源…
