Get the source code and install packages Configure Umami Create an .env file with the following: Optional: set API URL to change the base URL used by internal UI API calls. Relative paths are served under BASE PATH ; absolute URLs are proxied through the local /api route. For example, API URL=/internal-api or API URL=https://api.example.com/api . Optional: set TWO FACTOR ENCRYPTION KEY to a 64-character hex string to enable two-factor authentication. Generate one with openssl rand -hex 32 . Two-factor authentication is unavailable and cannot be required until this key is set.
