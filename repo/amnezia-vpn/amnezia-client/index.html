README 발췌

Amnezia VPN The best client for self-hosted VPN English) Русский Amnezia is an open-source VPN client, with a key feature that enables you to deploy your own VPN server on your server. Website Alt website link Documentation Troubleshooting [!TIP] If the Amnezia website is blocked in your region, you can use an Alternative website link. All releases Features - Very easy to use - enter your IP address, SSH login, password and Amnezia will automatically install VPN docker containers to your server and connect to the VPN. - Classic VPN-protocols: OpenVPN, WireGuard and IKEv2 protocols. - Protocols with traffic Masking (Obfuscation): OpenVPN over Cloak plugin, Shadowsocks (OpenVPN over Shadowsocks), AmneziaWG and XRay. - Split tunneling support - add any sites to the client to enable VPN only for them or add Apps (only for Android and Desktop). - Windows, MacOS, Linux, Android, iOS releases. - Support for AmneziaWG protocol configuration on Keenetic beta firmware.
