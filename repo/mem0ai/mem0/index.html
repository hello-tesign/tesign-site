Single-pass retrieval (one call, no agentic loops) at a top 200 retrieval budget. Scores reflect Mem0's managed platform, which includes proprietary optimizations not available in the open-source SDK; open-source users should expect directionally similar gains but not identical numbers. What changed: - Single-pass ADD-only extraction -- one LLM call, no UPDATE/DELETE. Memories accumulate; nothing is overwritten. - Agent-generated facts are first-class -- when an agent confirms an action, that information is now stored with equal weight. - Entity linking -- entities are extracted, embedded, and linked across memories for retrieval boosting. - Multi-signal retrieval -- semantic, BM25 keyword, and entity matching scored in parallel and fused. - Temporal Reasoning -- time-aware retrieval that ranks the right dated instance…
